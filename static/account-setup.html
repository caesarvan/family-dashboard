03 / 管理员配置

在自己的终端中填写凭证

在电脑终端连接服务器：

ssh -t racknerd

进入服务器后依次执行；可以先完成 Microsoft，再补 Google。

cd /opt/family-dashboard
python3 deploy/configure-oauth.py --provider microsoft
python3 deploy/configure-oauth.py --provider google
python3 deploy/configure-oauth.py --check

助手会询问 client ID，并让你两次粘贴 secret 的 Value。密钥输入不显示字符是正常现象。 原有家庭密码和另一平台的设置保留；原配置自动备份，配置与备份仅服务器账户可读写。检查命令只报告配置是否填写。

让应用读取新配置：

docker compose up -d --force-recreate app sync web
docker compose ps
curl --fail --silent --show-error https://home.caesarcharles.world/healthz

重建期间会短暂断开，已有数据保留。不要把密钥、.env 文件、完整环境变量或容器配置输出贴到聊天。密钥到期时，在原应用创建新密钥，再运行相同助手更新。

04 / 两位成员分别完成

绑定账号，选择准备共享的内容

  1. 用自己的原家庭密码登录，进入设置 → 账号与同步，绑定 Microsoft 或 Google。
  2. 在服务商页面核对账号和权限，授权后返回看板。
  3. 选择日历和清单，设置日程归属。所选来源内容会向伴侣和电视展示；未选择的来源不会自动导入。
  4. 选择一份 Microsoft To Do 清单作为家庭共同待办主清单。Google Tasks 是可选附加来源，不会复制成另一份微软任务。同一共享来源避免重复连接。
  5. 在原应用新建测试日程和任务，检查看板自动出现；在手机看板完成、恢复任务，在原应用核对。再检验修改与删除。
  6. 退出后使用已绑定平台登录，确认回到正确成员。伴侣用自己的家庭账号重复绑定；未绑定外部账号不会新增成员。

任务约 30 秒、日历约 60 秒由服务器检查，看板约 10 秒刷新。网络或限流可能延长等待，页面显示最近成功时间和异常。当前使用自动轮询，尚未启用第三方变更推送。

日程在原日历修改；看板支持新建共同待办、完成和恢复。任务详情、重复规则、删除在原应用管理。个人财务仍仅本人可见，电视只读；Apple 提醒事项后续接入。

返回家庭看板

遇到提示时

等待管理员配置

对应平台的 client ID 与 secret 尚未生效。完成服务器配置并重建容器，再刷新页面。该状态不代表账号已经授权。

回调地址不匹配

出现 redirect_uri_mismatch 或 AADSTS50011 时，核对 Web 类型、HTTPS、home 子域名和本页提供的回调路径，逐字一致且不加结尾斜杠。

Google 过几天需要重新授权

先检查是否仍为 External + Testing。本项目的日历与任务授权受该状态下的 7 天期限影响。发布后也可能因撤销、组织策略等原因需要重新连接。

工作或学校账号要求管理员批准

组织策略可能限制应用访问。由该组织管理员处理授权，不能用家庭看板设置绕过。

看不到某份日历或清单

核对实际绑定的账号、授权范围，以及来源在原服务中是否可访问；账号本人需要明确选择来源。同步报错时不会把旧内容当作空数据清除。

官方资料核查：2026-09-14。注册页面可能调整布局，请按字段名称查找。真实账号登录、刷新令牌与同步结果需在成员授权后验收。
