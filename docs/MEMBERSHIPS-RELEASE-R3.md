## 使用

- 从「更多 → 我的家庭账户」注册或绑定已有家庭身份。注册需要已有身份或有效邀请资格；同名不会自动合并。
- 从「家庭与成员」创建邀请码，将邀请码和家庭地址简称交给受邀人；受邀人核对后加入。管理员可移除成员，本人可退出；最后一位管理员需先安排另一管理员。
- 同一账户加入多个家庭后，可在账户页切换空间。个人财务、私人照片和原有对象范围保持，不因绑定或加入而自动共享。
