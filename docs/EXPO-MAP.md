# Expo 足迹地图与旅行相册

本次把已存在的地点与旅行相册操作迁入 React Native／Expo／Paper 界面，继续采用 [Expo 官网风格](EXPO-SITE-STYLE.md)。实际部署身份和验证结果以 [交接](HANDOFF.md) 与 [验证记录](VALIDATION.md) 为准；源码提交不等于已经上线。

## 家庭成员如何使用

从「更多 → 足迹地图」、电脑顶部「更多 → 足迹地图」，或旅行详情中的地图按钮进入。地图按“去过、已计划、想去”区分地点，列表与地图使用同一份当前授权数据。年份、成员、旅行和可见范围可筛选，超过一页时翻页；地图展示当前页有坐标的地点，并非全部地点的聚合图。

可以记录名称、国家、城市、日期和坐标，并选择关联已保存的旅行。默认仅本人可见；共享时可选择隐藏、模糊或展示坐标。地点名称与文字也可能暴露地址，填写时应考虑共享范围。只有本人明确确认才标记“已到访”，日期或照片不会自动确认到访。

选择关联旅行的地点后，可以查看旅行计划或该旅行的照片。旅行页面继续支持基本安排的预览、保存和准备清单；高级分段、资料及云日历操作仍有经典入口。旅行相册只展示本人当前可查看的照片，返回地图会恢复筛选、页码和选中地点，并重新读取权限。普通「相册」入口仍支持选片与管理。

## 模块与接口

| 文件 | 职责 |
| --- | --- |
| `frontend/src/screens/MapScreen.tsx` | 地点列表、筛选、详情、编辑与恢复 |
| `frontend/src/lib/places.ts` | 地点投影、输入校验和会话边界 |
| `frontend/src/ui/WorldMap.web.tsx` | 同源世界轮廓和地点标记；普通版本提供列表替代说明 |
| `frontend/src/screens/MapWorkspace.tsx` | 同一路由中的地图、旅行与照片切换，内存保存返回条件 |
| `frontend/src/screens/TripPhotosScreen.tsx` | 只读旅行相册，不读取账户、导入或设备管理信息 |

沿用现有 [地点 API](JOURNEY-PLACES.md)、[媒体 API](HOUSEHOLD-MEDIA-API.md) 与 [地图相册契约](MAP-TRAVEL-PHOTOS.md)。旅行实体的 `tripId` 和工作流 `journeyId` 各用各的接口，不能互换。没有新数据表、数据库迁移、云授权或依赖安装；[同源 Expo 托管](EXPO-WEB.md) 支持 `/app/map` 的直接访问与刷新。

地图底图复用 [Natural Earth 本地文件](MAP-BASEMAP.md)，没有外站瓦片、自动定位、街道导航或地理编码。地图不可用时仍保留可访问的列表和手工录入。地图可见不代表照片可见，照片关联也不自动共享或授予电视展示。

## 状态与验证边界

返回条件仅在当前页面、当前成员会话内保留筛选和 ID，不保存照片、坐标详情或草稿到 URL、浏览器持久存储。退出页面或身份变化会清理上下文；返回后读取最新数据，已删除或撤回共享的记录不能继续显示旧副本。

保存使用原有 revision 和幂等规则。遇到版本冲突保留输入并提示核对；创建响应不明时沿用原请求，不另建一条。只读相册在离线、后台或权限变化时隐藏内容，再次显示前重新检查。

当前范围为浏览器 Expo Web。原生安装包、实体电视、自动路线、地图照片自动回顾、真实用户新入口体验以及完整 A／B／C／D 场景须分别验收。本地合成家庭与模拟故障的浏览器验证不能代替 Google 账户或电视实测。
