# Expo 账户与同步

此文描述 React Native／Expo／Paper 的账户管理界面，路由为 `/app/connections`。实现遵循 [Expo 官网风格](EXPO-SITE-STYLE.md)：白色背景、黑色胶囊按钮、浅灰圆角区块，手机采用纵向卡片，日历／清单每页最多显示 24 项。源码提交、浏览器验收与实际发布是不同状态；以 [验证记录](VALIDATION.md) 和 [交接](HANDOFF.md) 的最终证据为准。

## 操作路径

1. 在「更多 → 账户与自动同步」或顶部「连接与账户」查看本人已连接账户，以及 Microsoft／Google 应用是否已配置。配置齐全、获得本人授权、已选来源和最近成功同步分别展示。
2. 点击「连接 Microsoft」或「连接 Google」，由本人在服务商页面授权。返回后重新读取真实账户；回调参数本身不作为成功证据。已有 Google 相册专用授权显示其能力，日历和清单需要另外授权。
3. 在目标账户点击「选择日历与清单」才发起远端来源发现。可以搜索和翻页；发现最多 500 个日历与 500 个清单，账户最多选择 12 项、家庭最多 24 项。未发现的既有选择仍被保留并标出，必须重新读取或明确取消后才能保存。
4. 日历可标注两位成员或共同，标注用于展示归属；任务必须共同共享，且必须有写权限。家庭主清单最多一份，也可暂不设置。同一账户设置新主清单时取消旧主清单；另一账户已有主清单时需由其拥有者先取消。
5. 勾选共享同意，点击「查看变更」，核对完整最终选择与所有取消来源后「确认保存」。所选日历完整标题、地点与任务会展示给双方和已配对电视。主清单额外允许家人把逐项确认的本地待办发布到该账户，不会自动迁移已有待办。
6. 「检查更新」只安排后台检查，不能视作同步完成。每个来源分别显示最近成功时间和错误；页面每 15 秒读取状态，后台任务约 30 秒、日历约 60 秒轮询，网络和限流可能延长等待。
7. 「断开绑定」需要明确确认。清除本地云端镜像，保留原平台原件；已发布的本地待办保留并停止云同步，后续照片导入停止。此前从该账户导入到看板的照片副本也会移除，家庭共享和电视展示一并撤销；Google Photos 中的原图保留。该云账户不能继续用于登录，家庭密码登录保留。

授权失效但仍有同步来源时，也可选择「停止日历与清单同步」：核对全部取消来源、勾选确认并预览后提交空选择。此操作使用已保存的版本，无需云端发现或重新授权；只移除日历／清单镜像并释放原主清单，**保留账户绑定、已导入照片及其家庭／电视展示许可**。原平台记录保留。确认前可以取消；冲突和未知响应继续使用下述同一套核对流程，不调用断开账户接口。

## API 与并发处理

沿用 [基础 API](API.md)、[账户同步](ACCOUNT-SYNC.md) 和 [待办发布](TASK-PUBLISH.md)。此界面只读取 `/me`、`/accounts` 和明确请求的 `/accounts/{id}/sources`；写入 bind、sources、sync、disconnect，不请求财务、设备或相册管理 API。

| 操作 | 行为 |
| --- | --- |
| `GET /api/accounts` | 本人账户与平台配置；账户包含不透明 `selectionVersion`，逐来源包含 `lastSuccess/error` |
| `GET /api/accounts/{id}/sources` | 真实来源发现，返回 `sources/selected/selectionVersion`，不自动选择 |
| `POST /api/accounts/{id}/sources` | `{sources:[完整最终选择],selectionVersion}`；每项使用远端 `remoteId`，不使用本地来源 ID |
| 409 版本／主清单冲突 | 保留用户输入，读取最新选择，显示差异上下文；只有点击「已核对最新选择，继续编辑」才采用新版本，重新同意并预览后才保存 |
| 保存响应丢失 | 保留本次完整选择，读取当前账户核对；相同选择只声明当前保存范围一致，不推断是哪次请求写入；不同则要求明确核对，无自动重发 |
| 断开响应丢失 | 重新读账户列表；已不存在时确认断开，仍存在则要求再次明确确认，不盲目重发 |

状态轮询不替换未保存的选择、搜索词或页码。来源重新发现也保留草稿，只补充可用性；新出现的服务端选择会在版本冲突核对中显示，最终取消项必须再次预览。同步时间和错误变化不改变选择版本。

## 身份、离线与可访问性

每次业务读写前后核对 `/me` 的成员 ID、角色、家庭、认证版本和 CSRF。屏幕隐藏、离线或 AppState 进入后台时隐藏账户详情；保留的草稿仅存在组件内存，恢复后核对本人账户才重新显示。路由离开与身份变更清空草稿及待确认操作。后台轮询不会吞掉输入，也不会执行自动来源发现或写入。

勾选支持键盘空格；来源选择、日历归属、主清单和账户动作有可访问名称。长名称允许换行；来源列表每页 24 项，确认对话框可滚动。此实现没有新增依赖，不代表 iOS／Android 安装包或实体电视验收。

## 验证入口

- `node --test tests/test_expo_accounts.mjs tests/test_expo_photos.mjs`：来源数量和权限、完整替换、未知写入比较、保留未发现选择、显式冲突核对及复用身份围栏。
- 组合源码的 `npm run typecheck` 与 Expo 网页导出由独立构建 worktree 执行，不通过 node_modules junction 冒充受验来源。
- 实际浏览器使用独立临时 Flask／SQLite、虚构账户与可控供应商适配器，核对真实 API 保存、冲突、断开、离线、身份切换和四种宽度。它不能替代本人真实云授权与长期同步验收。
