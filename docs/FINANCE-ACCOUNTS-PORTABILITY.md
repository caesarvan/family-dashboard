# 手动账户的个人数据副本

账户接入既有「导出个人数据」流程，不新增下载接口。ZIP 的 `data.json` 中
`personal.financeAccounts` 包含本人所有账户（含归档）、按日估值及最小操作摘要。
未知估值保持 `null`，明确零保持 `0`；金额为原币整数分，日期与币种保留。
个人导出摘要的 `personal.financeAccounts` 为本人账户总数，含归档。

即使选择附带家庭共同记录，伴侣的账户、估值和操作也不会导出。
数据投影使用 API 模块的显式字段白名单，操作只含类型、账户 ID 和完成时间，
不带请求编号、载荷散列、历史回执原文或未来新增的内部字段。
此组记录不加入来源报告、持仓、账本或公共资金汇总。

导出使用原有成员鉴权、家庭数据库、事务快照、生成后会话核验、大小限制和审计。
这里只读取手动账户表，账户业务数据不发生修改；导出审计记录按原流程保留。
JSON 下载不是数据库恢复包；完整备份和恢复另按部署文档执行。

新增验证使用真实 Flask 登录和临时 SQLite，覆盖双方成员、附带共享开关、
归档账户、全部日期、零与未知、未来字段过滤和导出前后业务表不变。
