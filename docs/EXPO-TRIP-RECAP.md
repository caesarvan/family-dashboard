# 单趟旅行回顾（Expo 候选）

此批只读组件已与旅行详情接线；R2 真实临时浏览器 10/10 流程、12 张截图的可见视口审查通过，尚未部署。固定来源、R1 失败与验证边界见 [组合验收](EXPO-TRIP-RECAP-ACCEPTANCE.md)。
沿用现有 Expo／Paper 浅深色、成员密度与 44px 操作区域；不新增路由、依赖、数据库表或写入接口。

## 使用流程

已有 workflow 的旅行入口为「旅行详情 → 旅行回顾」。页面显示当前旅行名称、日期以及三类内容：

- **行程安排**：保存的城市安排，以及当前仍关联的日程。城市顺序来自计划，不是实际路线；日程按当前开始时间排列。
- **关联地点**：本人私有及家人已共享、明确关联同一旅行的地点。每页 24 处，按最近更新排列，显示当前总数和本页覆盖。
- **旅行照片**：已确认保存、仍关联旅行且当前有权查看的照片，每页 24 张。点击「查看照片 N」重新鉴权后显示 JPEG。

「返回旅行详情」随时取消未完成读取；父页面应重新读取原旅行，不使用回顾副本替代详情。
回顾没有编辑草稿或写入动作，不需要全局未保存导航锁。

## 阅读口径

当前日程读取 detail 的 `events`，不会把已删除事项从旧 `plan.segments` 重新生成。
成员独立修改过的标题、地点、备注保留当前值。行程每页 8 项；城市最多为接口允许的 20 项，完整呈现。
航班与定时活动使用服务端保存的当地时刻和 IANA 时区；住宿未知入住／退房时刻明确显示未提供。
全天日期说明结束日不含，普通定时日程标北京时间。人工预订／取消只是保存的标记，不表示已向预订平台操作。

只有地点原记录明确确认到访时才显示到访。日期经过、照片或行程结束都不会推断已经到访。
家人地点坐标使用服务端隐藏／模糊／精确投影；不会还原坐标，也不读取地理编码或外站地图。
照片与地点关联同一旅行，不表示照片拍摄于该地点。照片预览不等于授予共享或电视许可。
空页、无日期、未提供坐标、坐标未共享分别显示。后续分页可能因删除／撤权而改变，空的后页可以回第一页。

## 组件与接口

`TripRecapPanel` 默认导出 props：`{journeyId: string; onBack: () => void}`。
`journeyId` 是工作流 ID；不是旅行实体 `tripId`。组件通过 `useHousehold()` 获取完整成员身份。
父入口只传 ID，成员／家庭切换应卸载面板。`onBack` 只返回宿主，不写路由或私人 DTO。

`tripRecap.ts` 提供旅程、地点及照片白名单投影、完整身份围栏与限量只读传输：

| 请求 | 用途 |
|---|---|
| `GET /api/me` | 每次读取前后检查角色、家庭、成员、auth version、CSRF |
| `GET /api/journeys/<id>` | 当前旅行、城市计划和当前关联日程 |
| `GET /api/journey-places?scope=visible&journeyId=<id>&limit=24&offset=<n>` | 当前可见地点分页 |
| `GET /api/media/items?scope=visible&journeyId=<id>&limit=24&offset=<n>` | 当前可见照片分页 |
| `GET /api/media/items/<id>`、`/<id>/preview` | 单张照片与真实鉴权展示副本 |

各资源分别读取，不构成跨模块同一数据库快照。结束时再核身份，不声称三个分类是同一瞬间的记录。
传输只允许上述精确相对路径，固定 GET、same-origin、no-store、拒绝重定向及 15 秒期限。
JSON 流读取最多 2,000,000 bytes，JPEG 最多 2 MiB；错误响应不展示任意远端错误正文。
不读取账户、来源令牌、原文件名、私人财务、资料内容、导入、设备或写入接口。

## 私密内容与失败恢复

在线约每 15 秒重新核对；读取时清掉旧内容。后台、路由或浏览器窗口失焦、pagehide、离线或身份变化清空 DTO、照片和 Blob URL，并中止请求；重新聚焦后读取。
只在内存保留分类、页码和照片 ID，返回后重新读取；不写 URL、history state、localStorage 或缓存。
所有异步回调检查实例、请求代次、焦点、可见性、连接及完整身份，返回后的旧请求不能重开面板。
401／403 或身份变化会清除并通知成员 provider 重新认证。其他错误显示「重新读取旅行回顾」，不保留旧内容充当当前结果。选中照片已删除／不可见时清除该选中 ID，下次明确读取恢复原旅行、原范围和原页，不自动扩大范围。

单张照片在 JPEG 读取前后核对详情和完整身份，详情版本或旅行关联变化即丢弃。
Blob URL 有本地最长 15 秒显示期限，计入读取时间，到期移除并重新核对。
已经交付浏览器的像素不能收回，事件循环完全冻结时也无法承诺实时擦除。
此候选只在 Web 使用 Blob 预览；原生端显示明确说明，不假称原生图片鉴权已验收。

## 实际验证与边界

运行 `node --experimental-transform-types --test --test-reporter=tap tests/test_expo_trip_recap.mjs`。
可用 `RECAP_TEST_PYTHON` 指定已有 Python，`RECAP_MODEL_BACKEND_ROOT` 指定固定受验真实源码。
测试通过真实临时 Flask／SQLite、成员与电视 cookie、媒体引擎和净化 JPEG 准备合成业务 DTO；网络被阻断，临时数据清理。
业务流程包括日程独立修改／删除、v2 时区与未知住宿时刻、两页地点／照片、家人私密隔离、坐标投影与撤共享。
纯模型另覆盖跨旅程、畸形分页、路径限制、前后身份、迟到失效、超大／畸形传输；不伪造成功业务 DTO 替代真实接口。
