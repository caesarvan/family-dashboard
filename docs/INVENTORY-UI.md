# 库存界面候选

`static/inventory-ui.js` 与 `static/inventory-ui.css` 提供独立、可在手机使用的库存工作区。以已审核心的 [数量与权限契约](INVENTORY-MODEL.md) 和库存 HTTP 作者约定实现；本候选不修改应用工厂、导航、HTML、Docker 或数据库。源码合入、实际 API 接线、迁移与生产发布分别验收。

## 挂载

先加载 CSS／JS，再在已登录成员的容器上调用：

```javascript
InventoryUI.mount(node, {});
InventoryUI.notifyStateChanged(); // shell 刷新：核对身份，保留同一节点的草稿
InventoryUI.notifyIdentityChanged(); // logout／成员／家庭变化：清空全部私密状态
InventoryUI.unmount(); // 离开页面
```

与既有相册界面相同，使用应用的 `user`、`csrf`、`isTV`、`isDemo`、`canEdit()`、`api(path)`、`write(path, method, payload)`；path 不包含 `/api`。HTTP 失败需保留 `error.status`，不要求每种认证错误都有 code。context 当前不需要额外回调。挂载会自动添加 `iv-workspace` class；相同身份、同一节点再次 mount 不重建表单。同步移除后重新附加同一节点不丢草稿；持续脱离 DOM 则清理监听器、定时器与私密数据。电视／演示模式拒绝挂载库存内容，也不读取库存接口。

## 可以完成的操作

- 新增默认私有的物品，填写单位、规格、位置、可选补货提醒线。拥有者可以编辑和明确共享／撤回；共享成员只能做被 API 允许的实物操作。
- 为物品添加采购或家中已有批次。下单状态、日期、预计到货、保修和售后均为手工记录；添加批次不会增加库存。已有批次固定 closed，必须另行明确登记已有数量。
- 同批次分次收货、使用消耗、报损、实物退回、带符号的余量更正。每次实物操作都需要独立确认；除收货以外须填写原因。反转保留原事件，追加相反数量，不删除历史。
- 分别显示现有库存、已下单待到货、计划采购、批次累计已收与退回。数字来自服务端投影，不由浏览器推算，也不代表付款、退款或估值。
- 物品／批次／流水分别按 24／12／12 条分页。搜索和查看范围交给 API；`shared` 标签为“已共享”，含本人已共享物品。分页没有历史快照，列表变化后可刷新或重新搜索。
- 库存为零且所有批次关闭或取消时，由拥有者明确归档。操作历史由后端保留。

批次编辑严格使用返回的 `editableFields`。普通共享成员无法编辑原数量、下单日期、保修或关联采购；不会把禁用表单里的字段重新传回。当前界面专注手工库存，不输入私人订单／金融来源、不创建购物或待办、不自动更改采购完成状态。

## 写入、断网与冲突

每次明确保存产生 32 位小写 hex `requestId`，原路径、方法、完整载荷只保留在当前挂载的内存中。写入和结果不明期间，目标切换、表单、筛选均锁定，避免画面与待确认请求分离。不会将私密草稿放入 localStorage，也不跨身份恢复。

网络／503 结果不明时，只在用户点击“核对并重试本次操作”后先请求原 `/operations/<requestId>`；已有回执采用当前投影，不重复 POST。404 无可读回执时才按原载荷和 ID 重试，最终 ACL 仍由服务端决定。410 表示已归档，清除旧详情，绝不另造请求复活。关闭或重载页面会丢失内存草稿；重新打开应先查看当前库存和流水，不能当作自动续传。

明确 400／409 后，保留草稿并要求用户点击“重新核对并修改草稿”；读取当前 revision，清理旧请求与实物确认，再由用户核对、确认并保存。不会自动覆盖冲突。每次 I/O 前后用 `/me` 验证成员、家庭、auth version 和 CSRF，加本地 epoch 阻止旧响应恢复私密内容；失权、归档或身份变化清空详情。空闲时每 15 秒只读核对可见性；编辑和待确认期间暂停，不干扰输入。

## 验证边界

```powershell
python -B -X utf8 tests/browser_inventory_check.py
```

该脚本在真实 Edge 上使用明确的合成 HTTP 库存契约，覆盖手机操作、分次收货／退回／反转、冲突重核、结果丢失后的原回执／原载荷、共享字段权限／撤回、分页搜索、身份晚响应、电视拒读、四种视口与同 tick DOM 重挂草稿。每轮保存新的 ignored `test-results/inventory-ui-<UTC>/`，包含结果、源码前后 SHA、截图和错误；异常退出非零，原失败保留。

这不是实际 Flask 库存 API、真实家庭、财务来源、物理电视或生产测试。实际 API 作者冻结后由集成人组合，另跑真实业务链；本候选没有运行迁移或生产操作。
