# Expo 日程与清单触控、密度

本轮已于 2026-09-17 18:13:25（北京时间）随旅行资料版发布；R2 真实临时浏览器 5／5 流程通过，18 图可见区域已逐张视查。仅调整 `CalendarScreen.tsx`、`ListScreen.tsx`，沿用[官网风格](EXPO-SITE-STYLE.md)和[成员外观](EXPO-APPEARANCE.md)；最终运行文件与受验字节一致，实际安装身份、原件与失败修正见 [集中验收](EXPO-JOURNEY-DOCUMENTS-ACCEPTANCE.md#expo-documents-release)。

## 使用变化

- 首页与日程共用的范围按钮保留「今日／本周／前后 3 天」。Paper 分段按钮使用 regular 密度，标签盒内增加留白，使内部可点击区域目标高度达到 44px；长选项分配更多宽度，不缩小字号。成员侧重复用现有 `SelectionRow`：48px 单选行、长名称可换行、Space 与方向键可用。
- 日程前后切换使用 Paper 图标按钮，R2 实测达到至少 44px；「回到今天」及本轮两页的文字操作使用至少 44px 的内容区。日期行可换行。查询范围、北京时间和全天日程排除结束日等规则不变。
- 日程、待办和采购的内容行采用既有密度值：标准纵向留白 10px，紧凑 6px；页面、清单工具间距随密度调整。正文大小保持原值，标题、地点与备注不设行数截断，颜色继续取 Paper 语义主题。
- 清单完成控件改用 Paper 图标复选框，R2 实测达到至少 44px；保留可访问名称、checked、disabled 和只读约束。Space 阻止默认重复激活及长按重复；点击继续调用原 `onToggle`，不增加另一条写入路径。清单过滤与搜索允许在窄屏换行。

保存显示范围仍调用原 `setMode`；偏好 CAS、未知结果核对与身份保护由原 provider 处理。本轮不修改 API、数据字段、日期算法、预算／实付计算、同步写入和电视布局。

R1 真实浏览器发现当前 React Native Web 不把 Paper 分段按钮的 `accessibilityState.checked` 呈现在按钮 DOM 上；刷新后实际周视图和服务端偏好正确，但选中状态缺少可访问表达。兼容修订仅使用 Paper 支持的 `accessibilityLabel`：未选名称保持原值，当前项增加「，已选择」，例如「本周，已选择」。视觉、按钮角色和保存逻辑不变，不修改依赖或运行时 DOM；R2 已核对完整可访问名称、七日日期和跨刷新持久化。
