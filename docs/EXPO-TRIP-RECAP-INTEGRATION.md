# 旅行回顾入口（候选）

入口分支最初基于 `690de2045fd487e9133a6649a98d1e1014e89b73`；现已与 `TripRecapPanel` 合入 R2 受验组合 `6453339dcc6fb8d3d60b1a21953c02b2ca205f74`，尚未部署。
接线只改旅行详情入口；完整组合证据及失败历史见 [旅行回顾验收](EXPO-TRIP-RECAP-ACCEPTANCE.md)。

已保存且具有 workflow 的旅行详情增加「旅行回顾」。只向面板传递 workflow
`journeyId`，不把当前页面中的行程、照片或地点对象当作已授权快照传入。
面板负责当前身份的重新读取、分页、隐藏与失效处理；入口保存的另一标识
`tripId` 仅用于返回时重新打开原旅行。

进入沿用现有旅行导航条件：当前成员与会话、页面焦点、非读取或写入中、
无旅行草稿或其他编辑面板。按钮离线禁用。返回回调额外核对当前面板引用，
迟到回调不能打开已离开的旅行；返回使用原有 `openTrip` 重新核对详情。
失焦时此只读面板关闭，不增加未保存状态或全局导航锁。

旧版未升级旅行继续使用既有完善计划流程。本文不把旧版旅行称为已支持回顾，
也不把回顾中的计划城市、可见地点或照片等同于实际路线或拍摄地点。

组件与入口分别经非作者审查，R2 `6453339d` 全量类型检查与真实临时浏览器 10/10 通过，覆盖授权变化、同旅行最新详情返回、迟到响应及窄屏交互，12 图经 Root 逐张可见视口审查。
未新增存储结构；验收使用合成数据，没有真实云请求或生产修改，原生及实体电视仍未验。
