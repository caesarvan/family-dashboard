# Expo 例行计划浏览器专项

候选脚本 [`browser_expo_routines_check.py`](../tests/browser_expo_routines_check.py) 已编写，尚未执行。需要另一位作者审查固定提交，再由集成人提供组合源码 HEAD 和真实 Expo export／build-evidence SHA；本文件不代表功能通过或已发布。

复用现有 finance `BaseRun` 的真实临时 Flask／SQLite／Edge、成员登录及失败截图，不修改旧夹具。所有计划和家庭均为虚构；主操作由可见 UI 发出，辅助准备走真实 API。SQLite 快照比较规则、期次、回执、实体、audit、settings，预览及只读恢复不得改业务记录。故障只丢弃或延迟真实 HTTP 请求／响应，不替换成功业务 JSON。

计划共 10 条流程：

1. 更多入口新建待办、键盘选择周期、预览零写、明确确认及真实 Flask 重启持久性。
2. 采购共同／成员负责人，预算未知 `null` 与明确零不同，不生成实付或照片。
3. 完成当前期只写一次，显式调用真实 worker `tick()` 恰好生成一期；暂停、恢复、跳过、归档分别预览确认，原事项和历史保留。
4. 同户另一成员共享管理；本人回执、跨家庭和真实配对 HttpOnly TV 管理权限隔离，电视仍可读已生成共享事项。
5. 真实并发版本产生 409，草稿保留；读最新、明确保留修改、重新预览后才确认。
6. 已提交丢响应保持未知与导航锁；GET 回执不重发，原 token 回放不重复生成。
7. 请求未到服务器即丢失，GET 404 仍未知；用户显式原请求重试只生成一次。
8. 真实签名时钟推进 601 秒：已写回执仍可读且不复活删除／归档状态；未写原确认精确返回 410 后才重新预览。时钟仅是测试夹具，不表示真实经过十分钟。
9. 离线／模拟后台隐藏但保留同身份内存草稿，迟到 GET 不恢复隐藏内容；明确弃稿解除顶部导航锁。
10. 真实换登录 Cookie 后，迟到预览和确认回执不带入新身份；共享计划本身仍合法可读。

截图计划为 320／390／1280／1920 各三张（浅色编辑、浅色确认、深色详情），共 12 张真实滚动位置截图，并检查页面横向溢出。仅在实际运行后逐图视查，不将未截到的内部 ScrollView 内容或屏幕阅读器体验算作通过。

运行参数沿既有冻结约束：`--source-root`、`--expected-head`、`--bundle`、`--expected-build-evidence`。每次使用新的 `test-results/expo-routines-<UTC>/`，保留执行脚本、失败截图／可访问树和最终 JSON；报告包含源码与导出前后散列、harness／夹具散列、外网请求、页面错误、临时目录清理结果。失败原件不覆盖，不运行生产、真实云或实体电视；显式 worker 调用不证明长期调度正确。不能在组合 export 冻结前宣称这些流程已经通过。
