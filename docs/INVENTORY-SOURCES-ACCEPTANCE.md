# 本人订单关联库存：验收计划

本增量正在开发，尚未合入或部署。目标是从本人已导入订单进入对应物品和采购批次，明确关联来源，再用已有收货、退回和售后流程跟进。订单引用不等于实物已到，也不新增支出、付款、退款或公共消费。

## 实际用户流程

1. 从财务账本的本人订单详情进入库存；保留原月份、搜索和订单详情，方便返回。
2. 选择该订单的商品行。数量原文只用于核对；库存数量与单位由本人填写。同名商品不自动合并。
3. 查看已有可见关联，或选择已有物品、新建私人物品及采购批次。已有成功保存记录可继续使用；取消后续来源关联不自动删除或重复创建它们。
4. 预览本人订单行和目标批次，明确确认关联。来源明细只向批次创建者本人显示，物品的共享范围另行管理。
5. 在批次详情明确登记收货、退回或售后。来源变化、删除和解除关联不改变实物数量或财务记录。

接口和 UI 作者各自维护精确契约与操作说明；本文件记录跨模块验证，不以一类测试替代其他证据。

## 隔离与证据

个人订单金额、编号和商品明细不进入共享库存投影、电视、公共财务或共享操作日志。个人导出和整库备份各自沿用当前白名单；需要独立核对新增来源的导出范围。

新功能沿用现有五张库存表，不计划 DDL 或金融表写入；这只是设计约束，合并和发布前仍需实际验证。Git 提交、测试通过、镜像构建与上线是不同状态，后续在本文件追加实际身份、命令、计数和限制。

实体电视暂不可用；本人实际订单样本、实体手机体验和云平台写入不在合成验证中冒充通过。其他完整家庭中枢目标仍继续推进。
