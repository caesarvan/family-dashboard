# Expo 通用账单四列映射（候选）

本批从 `08c0260b24e7ae917d5698dcbebde4fda6ff428d` 开发，仅修改导入客户端模型、现有 `FinanceImportPanel`、同模块 Node 测试及本文。默认自动识别保留；候选尚未组合浏览器验收或发布，不改变金融机构连接、金额算法、共享范围和数据库。

## 使用流程

1. 在「家庭资金 → 导入账单」选择「通用表格」、支付账单／订单记录和文件。CSV／TXT 沿用编码选择；XLSX 先点「预览文件」，再选择实际工作表。
2. 自动识别不适用时，展开「手动指定列」。表头所在行可留空，由服务端读取首个非空记录；也可明确填写 1–60 的整数，然后点「读取表头」。该步骤只返回列信息，不生成保存令牌。
3. 核对服务端显示的表头行，分别选择「日期列」「金额列」「标题列」「币种列」。选项显示列字母和原列名；列名重复或为空时仍按不同列选择，空名显示「无标题」。四个字段必须各占一列，币种不能省略或由客户端猜测。服务端的建议仅预选，仍需用户明确预览与确认。
4. 点「按所选列预览」，沿用「核对预览」的新增／重复／冲突／错误、原币整数分、源文件物理行范围与分页。错误行不在客户端重算；任何错误都会阻止确认，整份文件不部分入账。
5. 确认后仍用「确认导入 · 仅本人」，真实回执显示保存月份。保存结果不明时，只读「核对保存结果」；精确未找到回执仍可能在途，仅用户明确「使用原请求重试」才重发原意图。

「使用自动识别」关闭手动区并使旧预览失效。更换文件、来源、账单类型、工作表、编码或表头行会清除已读列、四列选择及旧令牌；更改任一列保留当前表头但清除旧预览／令牌。未重新预览不能确认。

## 协议与恢复

复用 `/api/finance-hub/imports/preview`、`/confirm`、`/results/<requestId>`。不新增路由，不直接访问银行或云端。

- 表头请求仅在 `source=generic` 使用 `inspectColumns:true` 与可选 `headerLine`，仍带原 `kind/file`；XLSX 先独立 `inspectSheets`，不能同次混用。表头回应为 `requiresColumnSelection:true`、`columnSelection`、空记录与空错误、`previewToken:null`。
- 映射预览仅带 `mapping:{version:1,headerLine,date,amount,title,currency}`；四个索引为 0–79 范围内、当前表头存在且互异的整数。不能夹带 `amountColumn`、`inspectColumns` 或 `inspectSheets`。
- `columnSelection` 校验行范围／原行类型、最多 80 列、唯一索引、准确列字母、有界原列名、四个建议及实际映射。列名允许空值或重复；建议可以未知，但正式预览必须明确四列。旧自动响应缺少整对新增字段仍兼容，部分字段或畸形新响应拒绝。
- 正式映射预览返回的映射必须等于本次请求；确认再次校验预览与请求一致，并深拷贝文件、映射、原 token 和 `requestId`。之后编辑对象不能改变在途恢复意图。预览错误、表头发现、工作表／金额列发现均不可确认。
- 既有未知恢复语义保持：原请求后续 400／404／409／5xx 或过期不能证明先前未保存，不能因此清除未知编号或自动再次入账。回执是历史事实，查看当前账本仍重新读取。

客户端新增导出 `ImportColumnField`、`ImportColumnMapping`、`ImportColumnSelection`、`readImportColumnSelection`、`inspectImportColumnsPayload`、`manualImportPayload`；既有导出保持。金额显示仍用现有整数分拆分，不做换汇、分摊或跨币种求和。服务端负责具体解析、去重和改变映射后的冲突判断。

## 隐私与可操作性

沿用完整家庭／成员／认证版本／CSRF 前后 `/me` 围栏、页面焦点、AppState、可见性、在线状态与请求 epoch。后台／离线隐藏私人表头、文件和预览；同身份恢复先核对身份。conceal 同时推进草稿 epoch，失焦期间迟到文件不能覆盖恢复后的输入。身份变化清除原面板，不存 localStorage，也不把私人数据写到 URL。

所有选择与输入在读取、保存及未知结果期间禁用；下拉回调还核当前读取／写入锁和原未知句柄，避免迟到点击更改恢复意图。新控件触控区至少 44px，Paper Dialog 的列选项可滚动和换行，采用当前浅深主题及标准／紧凑间距。浏览器关闭后的未确认草稿恢复不作保证。

稳定测试入口：`finance-column-mapping`；按钮／输入名称为「手动指定列」「使用自动识别」「读取表头」「表头所在行」「日期列」「金额列」「标题列」「币种列」「按所选列预览」。四个选列按钮的可访问名称不随值变化；选项名为「A 列 · 原列名」或「A 列 · 无标题」。确认及未知核对控件沿用原名称。
