# 本人手动资产账户：后端接入

这是依赖独立账户模块的接线候选，尚未组合验收或发布。该分支只将 `register_finance_accounts` 接入 `create_app`，并把 `finance_accounts.py` 加入 Docker COPY 和源文件发布白名单。账户接口、金额计算、权限和三表定义由独立模块提供，必须在模块审查通过后一起合入，不能单独部署本分支。

注册位于已有资产来源模块之后，沿用当前应用的数据库、Problem、请求正文、成员校验和审计依赖。每个独立家庭的应用工厂都走同一注册路径；不建立跨家庭共享的账户连接或缓存。账户默认仅本人，不修改原来源报告、持仓、荷包或共享汇总。

账户、估值和操作回执需要新的三张户内表。这里没有执行迁移，也没有通过启动应用更新服务器数据；实际发布须另行审查明确的 55→58 迁移、原 55 表及注册库保全、备份与恢复要求。原固定 55→55 发布工具不适用于新增表。

Docker 继续使用既有 Python 镜像和依赖。新增模块通过显式 COPY 与发布白名单进入候选，前端导出仍单独绑定真实构建；本接线不修改环境或安装依赖。

后续组合验收应在真实临时应用中检查完整注册、两家庭隔离、匿名与配对电视拒绝、同户伙伴私密边界、账户写入及重启读回，并验证最终包包含新模块。本人数据导出、Expo 入口与新 schema 的发布验收由各自增量负责；本文件不把尚未执行的检查描述为通过。
