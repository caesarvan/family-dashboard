# 私有资产与来源报告：读取会话边界

独立候选，基线 `7713ad1fd091d7390612c52d434b97e54e99f54b`。仅加固现有 `GET /api/finance-baseline/private`，与当前复杂旅行分段候选独立；未部署。

## 接口保持

- 仍只按已登录成员读取，查询参数不能指定另一成员或家庭。无基线返回 JSON `null`；匿名 401、电视 403。
- 完整私有基线、版本、金额、未知值及 `spending_observations.decorate_private_spending` 的消费观察选择和提示原样保留。独立消费观察不会与基线重复相加。
- 导入 preview/confirm/status、共享投影、表结构与财务计算均未改变，没有新增路由或依赖。

## 读取过程

1. 捕获请求鉴权所得真实会话 ID、owner、auth version 及成员家庭，使用现有 `member_sessions.current` 核对凭证与捕获身份一致。
2. 在同一 SQLite 事务快照中读取基线和消费观察，构造完整响应（也包括无基线的 `null`）。
3. 释放快照后再次读取真实会话；若读取过程中撤销、过期、auth version 变化或原浏览器已换会话，返回 401，不交付旧私有结果。

旧签名 cookie 的会话解析可能开启隐式事务，因此进入快照前、读取后与最后退出时均释放事务；最后检查不能继承旧快照。缺少会话引擎时返回 503，不接受假 actor 作为降级鉴权。此接口不提交业务写入；原鉴权层的访问时间、登录尝试等认证记账不属于业务数据。
