# Expo 例行计划入口

本分支仅接入「更多 → 家庭例行计划」，是尚未完成组合验证的候选。面板与接口由各自独立分支提供，不在本分支复制或占位。

`RoutinesPanel` 接收 `onBack` 和 `onPendingChange`；`ScreenProps.onRoutinesPending` 将未保存内容、处理中及未知确认结果交给 `HouseholdApp` 的既有导航保护。回调限定完整成员身份及当前更多页，来源为 `routines`，其他面板的迟到解锁不会清除此锁。明确结束操作后先通知解除，再返回更多列表。

父级按完整身份重挂内容，强制退出、刷新、后台和离线的具体内容处理仍由面板与 provider 负责。没有新增路由、自动云操作或业务请求；公共日程和现有清单处理不变。

接入需与真实面板组合后进行完整 TypeScript 检查和浏览器验证：从更多进入、预览确认、处理本期、读取后继、暂停，以及草稿或未知结果时顶栏／返回导航保持、明确放弃后可返回。当前仅静态差异检查，不能据此宣称界面可用或已发布。
