# Expo 资产来源导入入口

独立接线候选，尚未与面板组合验收或发布。财务页的「更新资产来源」接入 `FinanceSourceImportPanel`，传入 `onBack` 和 `onPendingChange`；具体文件处理、预览、确认与操作回执由面板负责。当前已上线功能以 README 为准。

进入前拒绝切换正在读取、写入、有未知结果或编辑草稿的财务工作区。进入时推进请求代次、清空财务显示并暂停后台读取的结果安装；返回后保留查询月份并重新读取当前账本。资产读取报告与来源导入是两个独立面板。

`ScreenProps.onFinanceSourcePending` 把面板的待确认状态接入现有全局导航保护，限制菜单、经典入口、页面离开及浏览器刷新。通知核对真实页面身份和财务路由；旧成员或旧面板回调不能锁住新页面。面板只有先解除自己的 pending 才能调用返回；未知结果如允许保留编号离开，必须由面板明确处理并解除 pending，接线不擅自猜测保存结果。

失焦或身份重置清除入口与导航锁；敏感输入及按成员／家庭隔离的恢复编号由面板处理。此接线不保存文件、预览 token 或财务数据，也不发起业务写入。

本分支仅修改财务页、共享 ScreenProps、HouseholdApp 的导航回调和本文；类型、真实浏览器及恢复流程在合入已审面板后的组合上验证。不得以接线源码完成代替完整交互验收。
