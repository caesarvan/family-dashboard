# 查询旅行准备情况

本功能已实现为候选，手机和桌面两条本地浏览器流程已分轮验证并通过独立审查，尚未发布；以下是候选界面的操作说明。[验证进度与边界](ASSISTANT-JOURNEY-STATUS-ACCEPTANCE.md)单独记录，不代表线上已经出现入口。

## 从问题回到原旅行

1. 打开「家庭助理」，输入“冰岛旅行准备得怎么样”“冰岛行程准备进度”或“旅行还有什么没办”，点击「查询」。也可直接点「查询旅行准备情况」，填写旅行关键词，或留空选择已有旅行。
2. 根据名称、日期和目的地选择，点击「查看这趟准备」。同名旅行不会自动选中；没有结果时可改关键词或「查看旅行列表」，不会自动新建旅行。
3. 在「准备事项」「采购事项」之间切换，查看尚未完成的事项、负责人、截止日期和任务前置阻塞；需要时翻页。
4. 点击「打开原旅行处理」，在原旅行完成或调整事项，再点原页的「返回助理」。它会回到本次准备查询，重新读取计数和阻塞；记录发生变化时从该类第一页重新核对。
5. 「返回候选旅行」用于换一趟；状态页的「返回助理」回到原问题。查询和选择只保留在当前页面，刷新页面后需重新查询。

只输入“还有哪些没做”或“还有什么未完成”，不会自动把全家庭待办问题当作旅行问题。需要查询旅行时，请加上“旅行／行程／旅游”，或主动点击专用入口。显式搜索、待办／采购输入、财务查询和旅行改期仍沿原入口；本功能不承诺理解任意问法。

## 怎样理解结果

查询只读本家庭已保存记录，即使开启 AI 整理也不会把这次旅行状态问题或家庭资料发给模型。它不会新建旅行、代替你完成事项或触发云同步。

计数来自可核实的原关联事项，不只是当前页。旧旅行尚无准备清单、关联失效或超出读取范围时，会明确提示“尚未建立可核对的准备清单”“关联准备记录需核对”或“仅核对部分已有旅行”。这些情况不能当作没有待办或全部完成。

“已记录的准备事项均已完成”只覆盖当前可完整核验的记录；真实预订、签证、未记录事项和云同步未在此核验。采购完成也不表示已经下单、付款或入库。无法确认的负责人、前置事项会标为待核对，不猜测姓名或完成情况。

## 断网、身份变化与保存结果不明

- 断网、离开前台或身份暂时无法核对时，查询内容会隐藏。同一身份恢复后重新读取；必要时点击「重新读取」，不要把旧计数当作当前结果。
- 切换成员或权限失效会清除本页问题、选择和结果。重新登录后重新查询；不能查看其他家庭或借电视身份查询。
- 原旅行不可用时不会跳到同名或另一趟旅行。没有未决保存时，可明确放弃未提交编辑返回查询；保存正在进行或结果未知时保留原页，不能用此入口丢弃未决操作。
- 如果在原旅行保存后提示“保存结果暂时未知”，保留当前页面，联网后点击「核对原保存」，沿用原操作核对；不要重新创建或重复提交一份新计划。若原页已关闭，先从旅行列表核对原记录，不承诺跨刷新恢复未决编辑。

字段、权限与覆盖范围见[接口契约](ASSISTANT-JOURNEY-STATUS.md)。
