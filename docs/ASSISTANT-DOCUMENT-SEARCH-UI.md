## 已约定的搜索接入

继续使用 `/assistant/search` 及本地搜索草案返回。资料匹配包含 `kind: "documents"`、32 位 `id`、`title`、`filename`、`mimeType`、正整数 `revision`、`visibility` 和 `journey: { id, tripId, title } | null`；不包含内容字节或下载授权。

入口只携带目标编号，资料页重新读取当前可见列表，照片页重新读取当前照片；目标删除、权限收回或移出原关联范围须明确失败并允许回到原搜索词与分页重新查询。搜索快照不直接生成下载、预览或共享授权。成员／家庭变化清除原内容，迟到读取不能安装到新身份。

## 使用与返回

在「家庭助理」点击「找资料照片」后修改关键词，或输入「搜索：关键词」「查找关键词」。资料按标题、文件名和当前关联旅行标题匹配；照片沿用现有说明和旅行标题搜索。不读取文件正文、执行 OCR 或搜索 Google 原图库。

结果标明资料／照片、文件名（资料）、仅本人／家庭共享和关联旅行。点击「查看资料」打开原资料详情，再由本人另点「下载资料」才读取文件；点击「查看照片」通过原相册详情重新读取当前照片。返回搜索会恢复原输入和页码，并重新读取当前可见结果。权限收回、文件移出原旅行或删除时显示实际失败，不能继续使用搜索时的快照。

资料和相册的入口参数均可选，原独立页面仍默认打开列表。资料编辑继续使用既有待处理与未知结果保护；照片已有未保存输入时，返回搜索先使用原放弃确认，不自动保存或共享。成员、家庭或会话变化会卸载原内容；后台及离线期间沿用原内容页的隐藏与重新核权机制。

## 实现接缝

- `lib/assistant.ts` 校验搜索分页、资料／照片编号和元数据，只保留允许的字段。目标只携带类型、编号、请求序号和资料的原旅行编号，不携带文件字节、图片地址、下载链接或共享指令。
- `AssistantScreen.tsx` 在原助理页内打开资料／相册，保留原查询与页码；不增加路由、依赖或后端写操作。
- `JourneyDocumentsPanel` 新增可选 `initialDocumentId`。`DocumentFence` 前后核对当前身份，再从原旅行列表或本人库查找同一编号。找不到时明确提示。文件下载仍由现有下载流程单独核权。
- `PhotosScreen` 新增可选 `initialPhotoId` 和 `onBack`。`PhotoReadFence` 重新读取原编号及当前权限，响应编号必须与请求一致；失败不能将搜索快照变成照片。显示和编辑沿用原详情。

后端候选为独立分支 `f48593f05ab62e20cc6faa7dddd213a4882c17d1`；API 由另一作者提交审查，没有复制到本 UI 分支。合入与完整端到端验收由集成人完成。
