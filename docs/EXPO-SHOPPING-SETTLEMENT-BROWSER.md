# Expo 采购实付浏览器验收

`tests/browser_expo_shopping_settlement_check.py` 在十个互相独立的临时 Flask／SQLite／HTTPS／Edge 环境中操作真实 Expo 入口。付款、订单、退款和采购全部为虚构内容，经真实 HTTP 持久化；不读取本人文件，不连接云或生产。脚本尚未实际执行，静态检查和提交不代表下列场景已通过。

## 场景与关键断言

1. **采购入口确认与持久化**：预览零业务写；明确确认只替换整项 `actual/done`，保留其余采购字段，重启后保持。伙伴只能看到共享采购结果，看不到本人付款标题、编号和私有关联；账本、预算、公共资金与旅行字段不变。
2. **交易入口与草稿**：未保存分类阻止进入；明确丢弃核对输入后保留原账本月份。订单未关联付款时无付款可选，真实核对订单与付款后才可投影实付。
3. **更新及解除**：更新保留原关联和付款；仅解除保留现值；安全恢复区分 `null` 与 `0`。删除采购后按原 `linkId` 读取并明确解除，不复活采购。
4. **退款与版本冲突**：预览后真实关联退款，原确认 409 且零实付写；显式重读保留金额草稿，重新预览后才保存。采购后来被修改时，安全恢复拒绝覆盖。
5. **确认已提交、响应丢失**：保留真实 200 原字节后丢弃响应，导航锁定；首次只读核对再次丢响应仍不解锁，成功明确 GET 后才可结束本地核对。只有一次 confirm，当前状态不冒充历史回执。
6. **确认未送达及原目标 404**：传输在请求到达前中止，真实删除采购后定位 GET 404；只允许明确读取本人当前可用资料并结束核对，没有实付写或重发。
7. **已确认但收尾失败**：分别丢弃子面板 context 与父清单 state 的真实 GET 200；旧操作不可恢复，只能重新 GET，确认计数不增加。
8. **私有权限与迟到身份**：伙伴／真实配对 TV 无权使用本人付款；真实预览返回前换为另一成员 cookie，旧面板卸载、私密结果不可显示、零确认写。
9. **后台与离线**：window blur、document hidden 和浏览器真实断网隐藏私密预览；同身份草稿在 fresh 身份与资料读取后恢复，旧预览失效，不自动确认。
10. **四宽与键盘**：320／390／1280／1920，各拍浅色输入和深色预览，共八张实际滚动后的可见视口；核对长标题、横向溢出和至少 44px 的主要动作。radio 方向键与 checkbox Space 精确改变选择，Enter 只预览、零确认写。

不扩展原财务模块全部矩阵。服务端双连接撤权、到期、写锁和审计后 rollback 由独立会话专项覆盖；本脚本不能替代真实平台文件、完整财务场景 B、设备或生产认证流程验收。

## 固定来源与运行

必须使用集成人已审、干净的组合源码。可复用已审祖先的构建，但相对原构建只允许本脚本和本文两个路径变化；还必须核对原 build commit／tree、全部构建输入与导出逐字节一致，不能仅凭 ancestor 关系放行。脚本、完整 tracked 源码与导出前后散列保持才可通过。原实际 build、受验 source 与自己的 harness 提交分别记录，不冒充重新构建；自身字节必须与 source 中脚本一致。复用的四份实际 fixture 为本脚本、`browser_expo_finance_check.py`、`test_financial_files.py`、`test_app.py`，记录实际加载路径／散列并在最终再次核对。

```text
python -B -X utf8 tests/browser_expo_shopping_settlement_check.py \
  --source-root <reviewed-source> --expected-head <40-hex> \
  --bundle <frozen-dist> --expected-build-evidence <64-hex>
```

父 `Run` 只提供本地应用、登录、HTTPS 服务、合成导入和浏览器生命周期；各场景有独立临时目录、数据库、context 和服务，SQLite 只读验证连接显式关闭。浏览器拒绝非同源请求，Python socket 拒绝非 loopback。故障只丢弃／暂扣实际传输，不伪造成功 DTO；原 POST body、实际状态及响应 bytes 留在自己的忽略输出目录，不进入仓库。

结果独占写到作者 worktree 的 `test-results/expo-shopping-settlement-<UTC>/`，包含逐场景状态、异常堆栈、失败截图／ARIA、实际响应与八张预期 PNG 散列。失败组不计成功，继续其他独立组；任意场景、外网、页面错误、来源变化或资源清理失败都使整轮失败，不把多轮部分通过相加。截图须另行逐张视查，只支持实际可见区域；不称完整页面／内部滚动／辅助技术或实体设备验收。`productionWrites=0`、`realFinancialData=false`、`realCloud=false`、`physicalTelevision=false` 单独报告。
