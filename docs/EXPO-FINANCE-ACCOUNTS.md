# Expo 本人手动资产账户

本模块提供本人手动资产、负债账户及按日估值的 Expo / React Native Paper 界面。
从「财务 → 我的资产账户」进入。已于 **2026-09-18 00:23:38（北京时间）上线**，00:24:23 正常 TLS 读回通过。当前为 58 张户内表；实际安装身份、组合检查及验证边界见 [发布验收](EXPO-FINANCE-ACCOUNTS-ACCEPTANCE.md#finance-accounts-release)。

## 使用步骤

1. 选择查看日期及“使用中 / 已归档 / 全部”账户范围。
2. 新增账户时填写名称，可选填机构、备注；明确类别和原币种。
3. 记录估值日期，选择“金额未知”或填写已知金额，点击“保存账户记录”。
4. 打开账户查看估值历史，可修改名称、机构、备注，或记录另一日期的估值。
5. 归档需要确认，估值历史保留；恢复账户后可继续记录估值。

币种和资产 / 负债类别创建后固定，不猜测机构类别，不连接银行或邮箱。
同一天再次保存会更新当天记录，其他日期保留；不提供当天每次修改的版本历史。
金额最多两位小数，资产和负债都填写非负金额。零是已知的零，不是未知。
机构、名称与备注按用户输入保存，不自动去除空格；名称不能全为空白。

## 日期、金额与私密范围

- 仅当前成员本人可见；界面不接收 owner 参数，也不显示伴侣账户。
- 查看日期只选择该日或以前最近一次估值；归档筛选采用账户**当前状态**。
- “手动账户已知部分”不是该日完整历史净资产，可切换“全部账户”查看含归档记录。
- 区分明确为零、已有记录但金额未知、截至日期尚无记录、估值早于查看日期。
- 逐币种展示服务器返回的已知资产、负债及净额；汇总整数分字符串用 BigInt 精确格式化。
- 所有金额未知时显示“暂无已知金额”，不把汇总中的零误称为完整净资产。
- 不跨币种换汇，不与来源报告、持仓、家庭荷包或账本金额相加。
- 列表包含最多 300 个账户，搜索覆盖当前筛选的全部已载入账户，每页展示 10 项。
- 历史使用服务器分页，每页 50 项；没有记录的日期不补造估值。

## 保存、冲突与恢复

正常保存只需明确点击一次。写入前后均重新核对当前成员完整身份；按钮在请求期间锁定。
版本冲突保留草稿；读取最新账户后，可采用最新信息或保留草稿，然后再次明确保存。
采用最新信息不会猜测估值金额，估值仍需重新填写。

响应丢失、非 JSON 或写后身份核验失败均不声称成功。原请求的操作编号和完整请求体在
同一身份的当前页面内存中保留；可“核对账户操作结果”或“按原账户请求重试”。
重试使用同一编号和相同请求体，重新取得当前 CSRF。历史回执只说明该次操作，随后另读当前账户。
确定保存成功但当前 GET 失败时，旧可操作详情失效，显示回执和“读取当前账户”。

`found:false` 只代表暂未查到结果，不会自动解除核对或重新提交。
只有 fresh `/me` → 当前全部账户 → 原编号 `found:false` → fresh `/me` 都完成后，
才提供二次确认的“结束本次核对”：**原请求仍可能完成，重新新建可能产生重复账户**。
结束不会自动新建；原编号仍可复制查询，下一次创建需独立填写和明确保存。
同编号相同请求可幂等重试；不同编号的新建没有全局账户版本约束，不保证去重。

离开未知操作前需要确认。离开或更换身份会清除私密草稿、原请求和回执，
仅在应用内存中按家庭和本人保留不透明操作编号；刷新 / 关闭应用前请自行保留编号。
新登录可以查询同一家庭中本人的历史操作，不借旧身份自动发起写入。
普通后台、断网和失焦隐藏私密视图，保留同身份草稿；重新展示前核验身份与当前版本。
不使用 localStorage，不把账户资料写入 URL；未保存 / 写入 / 未知状态通过父级 pending 回调保护导航。

## 客户端与接口

- `FinanceAccountsPanel({ onBack, onPendingChange? })`；入口及草稿导航保护已组合接入。
- GET `/api/finance-accounts?asOf=YYYY-MM-DD&status=active|archived|all`。
- POST `/api/finance-accounts` 创建账户与首条估值，`requestId` 为 32 位小写十六进制，创建 revision 为 0。
- PATCH `/api/finance-accounts/<id>` 修改名称 / 机构 / 备注 / 归档状态，携带当前 revision。
- PUT `/api/finance-accounts/<id>/valuations/<date>` 保存估值，携带当前 revision。
- GET `/api/finance-accounts/<id>/valuations?page=1&pageSize=50` 读取历史。
- GET `/api/finance-accounts/operations/<requestId>` 读取本人历史回执。
- 账户 ID 为 24 位小写十六进制；金额为整数分，单条范围 null 或 0 至 100000000000000（含）。
- 严格投影 DTO，核 owner / private、日期、版本、完整列表及精确小计；拒绝畸形或超大响应。
- 网络仅固定同源路径，no-store、redirect:error、30 秒截止、2 MB 响应上限，所有写请求带新核对的 CSRF。
