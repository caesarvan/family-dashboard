# Expo 我的资产与来源报告

本批是独立候选组件，尚未接线、浏览器验收或发布。界面沿用 Expo 白灰黑、Paper 浅深主题与成员内容密度；不改变电视和伴侣的设置。

## 查看方式

入口接入后，在财务中打开“我的资产与来源报告”。页面只展示当前成员自己的记录，没有选择其他成员的入口。

- **概览**：已记录人民币资产、负债小计，以及来源明确标记完整时的总额。资料不完整时，整体净资产显示待核对。
- **资产、负债、收入**：查看记录日期、币种、金额、来源、是否计入小计及排除依据。收入是历史来源记录，不推断当前工资。
- **消费观察**：分别显示支出、退款、净支出、报告生成时间、请求窗口和覆盖缺口。后来的独立消费报告不会改写资产记录。
- **来源说明**：来源报告日期、覆盖说明与文件清单。路径只作为文字展示，不打开或执行文件。

各明细分类支持在本分类全部记录中搜索，每页 10 条，用“上一页”“下一页”查看；不永久截断长列表。长标题与来源文字允许换行，新按钮最小操作高度 44px。

金额按整数分精确格式化。未知金额与零金额分别显示；旧消费报告缺少币种时显示“币种待核对”，不补成人民币。不换算汇率、不跨币种相加，也不与持仓、交易账本、家庭荷包相加。来源首尾月份可能不足整月；未出现的月份不表示没有消费。

“重新读取来源报告”只读取已存记录，不触发邮箱刷新、外部金融服务、导入或修改。空记录、读取失败和离线分别提示。页面切到后台、离开、断网或身份变化时清除私密数据和搜索词；同身份返回后也要重新读取，没有离线副本。

## 接口和集成边界

- `FinanceBaselinePanel` 默认导出，参数 `{ onBack: () => void }`。入口由独立接线改动提供，此分支不修改共享导航或 provider。
- 只允许 `GET /api/me` 和 `GET /api/finance-baseline/private`，没有 owner 参数；不消费 `/api/state` 的共享资产投影充当本人报告。
- 前后核对完整 `role/householdId/id/auth_version/csrf`，并结合组件身份、请求代次、焦点、前后台和联网状态拒绝迟到结果。401/403 清除显示并请求 provider 重新认证；真实身份变化需重新进入。
- 请求固定同源路径，`same-origin` 凭据、`no-store`、拒绝重定向；15 秒期限、可中止、4 MB 流式读取上限。无 POST/PUT、localStorage、外部 URL 或私密 provider 缓存。
- 模型校验 schema、当前 owner、日期、金额、逐项人民币汇总一致性和有界数组；投影已知字段，丢弃额外元数据。旧记录未提供的消费覆盖、质量或来源清单保持未知。
- 后端本人 GET 的一致读与会话最终复核由独立 API 分支提供，响应形状不变；客户端核验不能代替服务端权限检查。

稳定可访问名：标题“我的资产与来源报告”、返回“返回财务”、刷新“重新读取来源报告”，分类按钮为“概览分类”等。测试定位 `finance-baseline-panel`、`finance-baseline-content`、`baseline-search`；翻页按钮为“上一页记录”“下一页记录”。

## 当前验证

独立前端基线：`7713ad1fd091d7390612c52d434b97e54e99f54b`。模型测试通过 `BASELINE_MODEL_BACKEND_ROOT` 选择单一后端源码，实际使用已审 `expo-baseline-read-api` 固定 `362051f911d517aa7bd2d944789c08200560157c`，没有拼接后端文件。

`tests/test_expo_baseline.mjs` 用真实 Flask 登录、临时 SQLite 导入合成资产，真实消费观察预览/确认及真实 GET 取得 DTO；连接外网被禁止。最终 13 项实际通过，覆盖本人空记录、伙伴/电视/匿名隔离、独立观察、旧记录、未知与零、外币、完整与不完整汇总、精确金额、500 条分页、完整身份前后核验、迟到响应和传输拒绝边界。审查发现旧时间允许省略秒，补充了实际持久化的省略秒、空格分隔、紧凑日期/时区、ISO 周日期和时区秒数变体，与 Python 上海时间结果核对；无时区与非法日期仍拒绝。测试 fixture 的写入只发生在临时数据库，产品组件始终只读。

首轮 fixture 因 SQLite 连接未关闭，Windows 临时目录清理失败；已以 `closing` 确保连接关闭后完整重跑。时间回归首次构造未同步共享 importedAt，被真实服务端校验拒绝；修正测试输入后完整重跑。失败原件保留，各轮计数不相加。

本分支 `test-results/baseline-model-r5.tap` 与 `baseline-types-r3.txt` 保留最终原输出。模型和组件严格定向 TypeScript 检查为 0 diagnostics，使用现有物理依赖只读映射，没有安装依赖、junction 或生成应用导出。
