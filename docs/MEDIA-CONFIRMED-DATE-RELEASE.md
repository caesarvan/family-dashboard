`deploy/activate_media_date_release.py` 进入已有五服务控制器的 `media-date-source-update` 模式，前后均为 75／9。沿用发布锁、固定环境摘要、备份计时器停启、全部写入服务停机、完整家庭数据库组备份、仅应用启动后停止并逐表核验、再启动其余服务及 HTTPS 回读。数据读取与保全使用已有 `journey_finance_release_data.py`，包括非空旅行归集与操作记录；本模式没有 `migrate` 操作。
