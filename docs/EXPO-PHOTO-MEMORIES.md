# 相册：那年今日

从「相册 → 那年今日」查看本人保存的往年同日静态照片。页面按年份分组，显示来源日期，并说明没有可核对来源日期的照片数量。日期以服务端的北京时间为准，不使用看板导入日期推测拍摄日期。

点击照片仍打开原照片详情；关闭详情返回原回看分页。说明、旅行关联、共享与电视许可使用原编辑流程，没有第二份照片记录，也不会自动新增共享权限。页面隐藏、离线或身份变化时沿用相册的清屏和身份复核；回来后重新读取。

北京时间日期变化时返回回看的第一页，避免跨午夜后沿用昨天的页码而跳过今天的照片。页面暂时隐藏时只保留最后一次已核对的服务端日期用于这个判断；身份变化会连同日期一起清除。新日期的旧页结果不会短暂显示。

`photoMemories.ts` 校验专用只读接口的本人范围、日期口径、同月同日／跨年条件、固定分页、稳定排序及照片原 ID；`PhotosScreen` 复用既有权限检查、详情和图片访问路径。没有增加客户端日期参数或伙伴来源日期查询。

此界面属于独立候选，需与 [那年今日 API](MEDIA-MEMORIES.md) 合并后执行真实临时数据库／浏览器验证；辅助函数测试和类型检查不代替浏览器或本人在线验收。
