**开发候选，尚未上线。** 独立电视控制器、只读看板、短授权照片播放器与入口已实现，正在组合验收。当前线上仍为 2026-09-17 13:00 的[设备管理与手机控制版本](EXPO-DEVICES-ACCEPTANCE.md)，电视仍用经典渲染器。本页描述候选行为，不代表浏览器、真实云或实体电视已验收；最终构建、浏览器与发布结果待实际取得后补入。

## 使用路径

1. 在电视浏览器打开家庭地址的 `/tv`。候选安装且 Expo 导出有效后转到 `/app/tv`；`/tv?classic=1` 明确保留经典电视页，没有导出也回退经典页。两块电视分别配对，不在电视登录成员账号。
2. 未配对时显示「连接这块电视」与当前签名家庭，首次生成 8 位配对码，最长 10 分钟有效。手机进入同一家庭的「更多 → 电视与播放」（`/app/devices`），输入码并确认。页面给出精确 `/space/<slug>` 家庭入口，不自行切换家庭；家庭不符先核对入口。
3. 电视自动核对批准结果，成功后显示看板。码过期、网络中断或不确定请求结果时，先「重新核对连接」；确需新码再点「重新生成配对码」。一次自动生成失败不会静默重复创建码。
4. 手机分别为两块电视设置侧重成员、今日／本周／前后 3 天、卡片排序与隐藏、森林／晴日／海岸主题及舒适／紧凑密度。保持原[设备版本冲突与恢复规则](EXPO-DEVICES.md)，不会修改另一台电视或成员首页。正常前台共享状态约每 10 秒核对一次。
5. 照片拥有者先明确共享并单独允许这台电视播放，再由手机控制开始、暂停、前后切换或回到看板。开始播放不会自动扩大许可；使用见[手机播放控制](MEDIA-PLAYBACK.md)。

## 远距离阅读与空状态

看板只读呈现日程、共同资金、未完成待办、采购和接下来的旅行。侧重成员影响排序及工作量摘要，保留本人、伴侣与共同安排；不以侧重设置扩大私有数据权限。本周为周一至周日，前后 3 天包含今天共七天，按上海时间分天。

显示以 1920×1080 CSS 视口为基准缩放，保留每台设备独立主题与密度。卡片按可用空间分页，每页至少 20 秒；长标题、地点和清单文字通过测量延长停留并分段自动滚动，供无触屏设备阅读。照片保持自身比例，加载提示与计数也随视口缩放。CSS 视口不等同屏幕物理像素；50／75 英寸、浏览器缩放及遥控器仍须实机检查。

没有日程、采购或旅行时显示真实空状态；共同资金未核对时显示「待核对」，不填模拟余额。照片模式只显示当前有许可的 JPEG；没有可播放照片、加载失败与授权待核对分别提示。断网、页面隐藏或无法核对连接时清除家庭内容，恢复后重新读取，不依靠离线缓存继续播放。

## 复用接口与身份边界

本轮不新增业务 API、依赖或数据库结构；仍为 55 张业务表和 2 张平台注册表。电视根布局排除成员 `HouseholdProvider`，不加载成员管理页面及个人财务接口。电视请求使用同源 Cookie、`X-Display-Mode: tv`、`no-store`、禁止重定向及超时；签名家庭、电视设备和异步请求代次都需一致。

| 请求 | 用途与核对 |
| --- | --- |
| `GET /api/me` | 只接受有效 TV 角色；成员 Cookie 不替代电视配对 |
| `GET /api/spaces/current` | 核对当前签名家庭及安全家庭入口 |
| `POST /api/pair/start`、`POST /api/pair/poll` | 生成／核对配对；轮询 secret 仅留内存，电视 Cookie 由服务器设置，不另写客户端存储 |
| `GET /api/state` | 在两次 `/api/me` 间取得同一电视允许的共享状态和 `display` 设置 |
| `GET /api/media-tv/playback` | 独立只读播放状态、设备／版本／位置及短显示授权 |
| `GET /api/media-tv/items/<id>/preview` | 使用实际电视 Cookie 重新验证许可后读取 JPEG，不接受外部 URL |

照片授权最长 15 秒，从请求开始的单调时钟计时，网络与解码耗时也占用授权；暂停仍需续期。下载限制 2 MiB，校验 JPEG、解码尺寸和当前设备／版本／位置，渲染前再次核对请求代次与截止时间。页面隐藏、断网、卸载、授权失效或超时会中止旧请求、清除图像并撤销 Blob URL；迟到响应不能恢复旧照片。401／403 让控制器重新核对电视身份。播放器没有成员写请求、本地持久化、HTML 注入或 data URI 入口。

上述行为约束客户端正常执行时的显示，不承诺远程抹除已截屏内容、操作系统缓存或冻结的实体屏幕。共享状态可见不代表私有账本、个人账户、投资、媒体原图或精确私人位置可见。照片共享与逐设备许可仍分别由拥有者明确决定。
