导出与构建证据执行；静态编译不构成功能、视觉、生产或真实云验收。入口和业务契约见

复用 `browser_expo_finance_check.Run` 的真实 Flask HTTPS loopback、独立 SQLite、HttpOnly
成员 cookie、Edge context、截图和资源清理。每组新建临时数据库与服务器，前一组失败也继续收集其他组；
任一失败、外网请求、页面错误、源码／导出变化或清理失败均使整轮失败，不能相加历轮部分通过数。
不调用生产、云端或模型，不访问本人旅行／财务／照片；成功业务响应均来自真实后端。

十二组覆盖：

1. v1 BOM 文件与 `{plan}` 包装：省略版本、成员、清单、分段时使用真实服务端默认值；显式空数组保持空。
   确认后核 SQLite 工作流、实体与关联数，重启服务后读回原计划。
2. v2 文件和粘贴预览一致：四类分段、当地时间／时区、未知住宿时刻、全天结束日、人工预订状态，
   分页可读末项；预算整数分、采购 null／0 与负责人落库，保存后进入已发布的分段编辑器。
3. 空／坏 JSON、UTF-8 字节超限、空／坏编码文件、注入已有目标或令牌拒绝；真实非法成员及 DST 重叠／缺失时间
   返回原错误，输入不被猜测性更改，只有用户修改 JSON 中服务器给出的 offset 后才重新预览，全程零业务写入。
4. apply 真实提交后丢回复，首次真实回执 GET 也丢回复；未知状态保持，明确再次 GET 后读取当前详情，零重复 apply。
5. 双击只发送首次一次 apply；已提交丢回复、核对失败后明确重试完全相同 token／key，真实历史 200 不重复创建。
6. apply 未送达、operations 真实 404 仍未知，父导航与返回不能丢意图；fresh 列表＋回执核对后两次明确结束，
   保留编号而清输入，不宣称未提交；重新输入／预览／确认才可另建。
7. 未提交预览过期实际 409 且零写；已提交的普通 apply 即使过期也先 409，仍用原 key GET 恢复。
   本人新真实登录可通过历史查询入口读取回执，没有原 token 时不能重试写入。
8. 实际保存成功后，子面板首次详情 GET 或父接线第二次详情 GET 丢失，只保留已确认保存与重新读取入口。
   暂扣父 GET 后隐藏页面，迟到结果不得打开详情；恢复后明确读取，不能重新 apply。
9. 本人回执与 token 拒绝伙伴、签名第二家庭、匿名、真实配对 TV；同户伙伴仍可读合法共享旅行详情，
   不把旧只读权限改称泄露，TV 不进入成员导入面板。
10. 真正完成的 preview 在成员／家庭 cookie 替换后才返回，旧 JSON／token 不进入新身份，旧面板卸载。
11. 未提交草稿需明确放弃才解导航锁；同身份 hidden／blur／offline 隐藏而保留内存输入。
    迟到原生 FileReader 和真实 preview 不覆盖新草稿，返回与明确放弃可继续操作。
12. 320／390／1280／1920 四宽：浅色长内容、内部滚动确认区、深色紧凑键盘焦点共 12 张 PNG；
    新按钮实际点击框至少 44px，预览不写、键盘确认只写一次。截图需另行实际逐张视查，只覆盖当时可见视口。

所有传输故障只暂扣／丢弃真实 GET 或 POST；普通成功先保存真实原 bytes，再原样转发，避免浏览器响应体生命周期竞态。
迟到文件只延迟原生 `FileReader.readAsArrayBuffer` 在原 `File` 上的执行，保留字节及真实 loadend；不替换解析结果。
过期用局部签名时钟偏移，不声称等待了真实 30 分钟；hidden／blur 用生命周期事件，离线用浏览器网络状态。
