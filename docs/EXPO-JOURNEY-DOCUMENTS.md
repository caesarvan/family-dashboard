# Expo 旅行资料

**独立实现候选，尚未完成组合浏览器验收或发布。** 本面板复用已存在的旅行资料 API，不新增表、文件服务或外部授权。此前经典资料服务的发布事实不代表本次 Expo 界面已上线。接口与限制见 [旅行资料](JOURNEY-DOCUMENTS.md)。

## 使用

1. 从已保存旅行打开「旅行资料」查看该旅行中本人及伙伴明确共享的凭证；「我的旅行资料」仅列本人上传内容，也包含删除旅行后留下的文件。
2. 点击「上传资料 → 选择资料文件」，选择 PDF、JPG、PNG 或 WebP，每份不超过 5 MB。填写 1–120 字标题、关联旅行和可选分段，再点击「确认上传资料」。资料库上传须先选择一个现存旅行。
3. 默认「仅本人可见」。明确选择「与家庭共享」后，伙伴才能在该旅行内查看并下载；伙伴没有编辑或删除入口。资料不会出现在电视、助理或云日历中。
4. 列表可按标题／文件名搜索，每页 12 份。打开「查看资料」后点击「下载资料」，浏览器取得经过鉴权的附件；页面不内嵌 PDF，也不自动打开文件内容。
5. 上传者可通过「编辑资料」修改标题、共享范围、旅行或分段，明确点击「保存资料修改」。解除关联会强制仅本人并清空分段；之后可在资料库重新关联到现存旅行。
6. 删除需「删除这份资料 → 确认删除资料」。这会移除文件与共享入口，不撤销预订、不更改旅行日期，也不能在界面内撤销。

图片由既有服务去除 EXIF／GPS 等元数据并重新编码为 JPEG，不是原图备份；请下载核对细小文字及二维码。PDF 只做现有格式外形检查，不代表病毒扫描、完整性或预订真实性验证。

## 冲突与恢复

| 情况 | 界面处理 |
| --- | --- |
| 保存前身份核对失败 | 未发送写请求，保留草稿并提示；不假称保存，也不错误登记为未知写。 |
| 上传回复丢失、超时或后置身份检查失败 | 保留整份原文件载荷与 requestId；「核对资料当前状态」只 GET。「按原请求重试上传」才显式重发完全相同的请求。 |
| 上传重试返回原文件当前元数据 | 展示实际结果，不恢复旧标题、共享范围或关联；已解除／改变旅行关联时提示从本人资料库查看。 |
| 编辑／删除回复不确定 | 不自动重试；读取本人当前资料库并显示当前状态。编辑可明确采用或保留本人改动，保留后仍需再次保存；删除须重新经过确认。 |
| 编辑／删除 409 | 保留草稿，先「读取最新资料」，核对版本后明确采用或保留差异。上传的关联／容量冲突保留输入，供修正后明确提交。 |
| 当前列表不再包含资料 | 不将缺失当作某次请求成功或未执行的证明，不自动重建。旅行消失时可读取本人资料库，文件仍由既有服务保留。 |
| 同一完整身份后台、离线或失去焦点 | 隐藏私密界面、取消旧请求，草稿与未知意图仅留在内存；返回后先核对身份及当前列表，版本变化进入明确选择。 |
| 成员、家庭、认证代次或 CSRF 改变 | 清除旧身份内容；迟到成功、错误与下载不能恢复旧界面。 |

未知上传在读回后也可明确选择「结束本次上传并返回列表」并二次确认。界面说明这不会撤销服务器可能已保存的文件，结束后不再保留原请求编号。普通未保存编辑需明确放弃后才能返回。强制关闭浏览器不提供跨会话草稿恢复；文件、请求编号和私密元数据不写 localStorage 或 URL。

## 组件与接口

`JourneyDocumentsPanel` 默认导出，props 为 `{journeyId?: string, onBack: () => void, onPendingChange?: (pending: boolean) => void}`。省略 journeyId 为本人资料库。面板从 `useHousehold` 获取完整身份与联网状态，以身份及旅行键重挂载；父级负责旅行、更多及嵌套导航接线。编辑、文件读取、写入和未知结果通过 pending 回调保护导航；同身份暂时隐藏不释放仍有草稿／未知意图的锁，明确退出先解除锁再调用 onBack。

- [JourneyDocumentsPanel.tsx](../frontend/src/screens/JourneyDocumentsPanel.tsx)：Paper／浅深主题及密度、分页、选择文件、内存草稿、显示生命周期、明确操作与 Blob URL 释放。
- [journeyDocuments.ts](../frontend/src/lib/journeyDocuments.ts)：独立作者提供的 DTO 白名单、字段与大小校验、完整身份 fence、同源 no-store／禁止重定向／超时传输、上传幂等载荷、附件下载校验。本分支不复制该并行文件。
- 读取为 `GET /api/journey-documents[?journeyId=…]`；服务端不提供搜索或分页，因此客户端只在返回的授权列表中搜索／分页。
- 上传 `POST /api/journey-documents`；编辑 `PATCH /api/journey-documents/<id>` 五字段完整替换并携 revision；删除 `DELETE` 携 revision。没有单份元数据 GET 或操作回执端点，未知修改只读取列表核对。
- 下载仅 `GET /api/journey-documents/<id>/file`。ID 构造固定同源路径，前后核对身份，检查附件 MIME／大小／禁止缓存后才创建临时 Blob 下载链接；及时撤销链接，后台及卸载也清理。不信任外部下载 URL，不执行文件或元数据。

列表、关联旅行／分段选项每页 12 项；按钮最小高度 44px，选择行至少 48px，长标题和关联名可换行。实际移动设备文件选择、下载体验、全尺寸视觉与触控效果仍需组合浏览器／设备验收，样式声明不是实测结论。
