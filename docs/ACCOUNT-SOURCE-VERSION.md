# 云账户来源选择的版本与会话保护

此文补充 [账户 API](API.md#93-来源发现)。实现位于 `cloud_accounts.py`，复用已有账户／来源／成员会话表，无数据库迁移。适用于 Microsoft 和 Google 日历、任务清单的来源配置；不会新增云端写日历权限。

## 读取与保存

`GET /api/accounts` 的每个 `accounts[]` 对象新增 `selectionVersion`。`GET /api/accounts/{accountId}/sources` 根对象新增同名字段；其 `selected` 和版本来自同一个数据库读取快照。

```json
{
  "selectionVersion": "64位小写十六进制字符串，客户端按不透明版本处理",
  "sources": [{"id": "remote-list-id", "kind": "tasks", "name": "共同待办", "writable": true}],
  "selected": [{"id": "local-source-id", "remoteId": "remote-list-id", "kind": "tasks", "name": "共同待办", "owner": "shared", "primary": true, "lastSuccess": "", "error": ""}]
}
```

上例版本是说明文字，不能原样提交。发现列表 `sources[].id` 为远端 ID；已选 `selected[].id` 为本地 ID。

保存仍是完整替换。新版客户端将编辑开始时取得的版本原样带回：

```json
{
  "selectionVersion": "从最近一次读取复制的真实版本",
  "sources": [{"remoteId": "remote-list-id", "kind": "tasks", "owner": "shared", "primary": true}]
}
```

服务端先验证版本格式及选择数组数量，按需重新发现远端来源并校验每项配置；在 `BEGIN IMMEDIATE` 事务中重新验证成员会话和账户归属，再比较当前配置版本。比较失败时返回 `409`：

```json
{"error":"来源选择已被更新，请重新读取后确认保存","code":"selection_conflict"}
```

冲突事务不会清除主清单、删除镜像、改变归属、创建来源或更新同步排队时间。账户锁忙和另一个账户已经占用主清单也可能返回 `409`，但没有 `selection_conflict` 代码。客户端应保留草稿，重新读取并让用户核对差异后再明确保存，不能自动用新版本覆盖另一台设备的选择。

成功响应为 `{"ok":true,"queued":true,"selectionVersion":"保存后的真实版本"}`。`queued:true` 仅代表存在已选择来源，已将它们排入后台同步；不证明远端内容已读取完成。数组为 `[]` 时取消全部来源，返回 `queued:false` 和空配置的新版本；其镜像删除规则仍见原账户 API。

`POST /api/accounts/{accountId}/sync {}` 也返回准确的 `queued`：存在已选来源时为 true，没有来源时为 false。它不等待同步完成，不调用云端 API。仍需读取逐来源的成功时间和错误。

## 版本含义及兼容边界

版本为账户 ID 及按本地来源 ID 排序的配置行之 SHA-256；每行包含本地 ID、类型、远端 ID、归属与主清单标记。显示名称、成功时间、错误、重试次数和下次轮询时间不参与计算，后台同步进度变化不会使用户的编辑过期。版本不含令牌、邮箱或其他账户资料。

删除来源后重新添加同一个远端来源会生成新的本地 ID，因此旧版本不能绕过这类删除／重建变化。它是当前配置的内容摘要，不是单调递增的历史序号；如果没有重建 ID，配置改动后完整恢复原值会得到原摘要，空配置恢复为空亦然。

省略 `selectionVersion` 继续接受经典界面及旧的服务端调用，**该路径没有来源配置 CAS**；显式 `null`、非字符串、大写、长度不符或非十六进制值返回 `400`，不会退回兼容路径。新增 Python 参数为 keyword-only，原 `select_sources(account_id, owner, chosen)` 调用仍可使用。旧调用获得的新增返回对象不会改变原写入规则。

请求发送后连接丢失属于结果未知。客户端可重新读取本人账户的来源和版本，核对是否已保存；不能将超时视为保存失败后无条件重放完整替换。若来源没有变化，重复保存可保留相同版本并重新排队，因此版本也不是一次请求的幂等回执。

## 撤销与隐私

账户列表、来源 GET／POST 和手动同步在路由入口捕获当前 `member_sessions` 上下文。来源保存和排队在写事务中验证原浏览器代次、成员会话、有效期、认证版本及账户归属；空数组不做云端发现，但同样要求有效成员。云授权失效与成员会话失效是不同情况：前者允许仍有效的账户拥有者清理旧来源，后者不得继续删除或排队。

来源发现完成后再次验证上下文，账户成功响应在发出前还有一次会话检查。会话失效返回 `401`，浏览器认证代次已更新可能返回 `409`，不返回原来的私人账户／来源 DTO。响应保持 `Cache-Control: no-store`。这不是任意时点的网络撤回保证；在最后权限读取以后才撤销的请求可能已经开始发送。

发现过程中刷新令牌时，令牌持久化事务也验证当前 HTTP 会话。云端返回重新授权错误时，只允许当前有效成员对同一账户授权快照写入 `needs_reauth` 和来源错误；过期 HTTP 请求不能把后来状态标为失效。该错误记录在原账户锁内执行。后台 worker 不持有浏览器上下文，继续按原接口记录其实际同步失败，本次没有关闭后台错误记录。

其他成员／家庭不能管理本人的账户，即使清单在家庭中共享；电视不能列出或管理账户。云来源仍按现有明确选择规则接入，不自动扩大共享或获得额外 OAuth 权限。

## 验证范围

`tests/test_account_source_version.py` 使用真实 Flask 路由、SQLite、成员会话、双设备客户端及线程中的阻塞发现。测试覆盖保存冲突、发现期间的并发提交、版本稳定性、删除重建、旧客户端、空来源排队语义、撤销／过期／认证版本／浏览器代次变化、撤销后的云错误和令牌刷新、读取后的响应拦截、其他成员／真实独立家庭／电视拒绝，以及后台错误记录保留。云端身份和来源由测试适配器提供，并禁止外部网络连接。

配套回归包括既有云账户、云权限、Photos OAuth 和同步健康测试。测试结果与部署身份由集成人写入发布验证记录；此功能分支不构成生产部署或本人真实云端验收证据。
