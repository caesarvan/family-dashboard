# 助理地点入口的真实本地浏览器验收

此工具是验收准备，提交工具、离线检查通过都不表示三个 Edge 流程已经通过，也不表示上线。使用独立临时 Flask／SQLite／HTTPS 和同源码的真实 Expo 导出；旅行、地点、本地照片净化、确认与详情都走真实 API。禁止模型、地图提供方、Google 和其他公网请求，不替换业务 DTO。

## 三个可独立选择的流程

| case | 实际检查 | 预期截图 |
|---|---|---|
| `page_original_return` | 390px；创建 21 个匹配地点和 24 个较新的填充地点，证明搜索第二页的原 ID 不在地图第一页。打开原详情、按原 revision 编辑一次、打开原旅行与已明确保存的旅行照片，返回同 query／offset，核对真实数据库无地点副本、旅行和照片不变。 | 3 |
| `filters_clear_selection` | 1280px；普通刷新保留原 ID；主动年份筛选、重置、前后翻页清除旧选择，返回原搜索第二页，业务表不变。 | 2 |
| `revocation_identity_late` | 1280px；伙伴只读粗化坐标，离线隐藏与恢复；创建者通过真实 PATCH 撤回共享，等待真实 15 秒权限轮询拒绝旧详情。另持有已完成的真实私人详情 GET，真实登录替换成员后再交付原字节，前后 `/me` 围栏清屏且新成员搜索为空。 | 3 |

照片由小型合成 PNG 经本地上传、净化加密、明确确认和旅行关联生成，没有伪造 Google 媒体 ID。真实照片详情不增加共享或电视许可。身份场景中仅延迟原 HTTP 的交付，状态码、正文及最终权限均来自真实服务器。跨家庭／电视 ACL 不是本工具新增的独立验收范围。

## 固定构建与执行

先由非作者审查工具的固定提交。构建提交必须是验收提交的祖先，完整 `frontend` tree 与全部 `build-evidence.json.inputFiles` 字节完全一致，差异仅允许此脚本、场景文件、对应离线测试和本文四个精确路径；23 个导出文件按实际构建原件核验。不要因文档或工具改变重新 npm／导出。

```powershell
python -B -X utf8 scripts/check_expo_assistant_places_browser.py `
  --source-root <固定独立源码目录> --expected-head <40位已审提交> `
  --build-source-head <40位构建提交> --bundle <同构建的web绝对目录> `
  --expected-build-evidence <64位构建原件SHA256> --temp-root C:/tmp
```

可重复传 `--case`，按首次出现顺序去重；不传则运行三项。失败后保留原件，只在修复经独审并明确安排后补验受影响项，不把分轮结果写成一次全量通过。Windows 导出复制使用扩展绝对路径，以免字体资源长路径导致准备失败。

每个请求等待在触发前注册确切 method／URL 的 response 与 `requestfinished`，有 15 秒上限，确认同一请求后才读取真实 JSON；不使用无界 `Response.finished()`。阶段回执在易等待步骤前刷盘。权限轮询等待有 25 秒上限，不靠任意 sleep 假定完成。每项独占短临时目录，数据库 `closing`、服务器非 daemon 请求线程关闭和场景收尾均须通过；收尾失败整项仍为失败。

原件位于忽略的 `test-results/expo-assistant-places-*/`，包括实际 HTTP／数据库摘要、截图、请求阶段、失败截图与 aria、固定源及导出前后哈希、临时目录清理结果。只记录合成测试资料，不读取生产配置或数据库。离线测试检查构建白名单、独占输出、真实 SQLite 分页／粗化／撤权及连接关闭；它们不启动 Edge，也不替代以上端到端流程。
