## 最短操作

相册 → 我的照片 → 已保存的设备照片 → 本人确认日期 → 填写 `YYYY-MM-DD` → 保存照片日期。已有日期可明确清除。若照片其他设置有草稿，先保存或放弃；日期不会连带保存说明、共享或旅行设置。

保存后可查看旅行建议，核对后明确关联；「那年今日」按本人确认日期或可靠来源日期回看往年同日。清除日期不会解除已有旅行，也不会撤回已经明确设置的家庭共享或电视许可。日期不能证明到访，不改写原始拍摄时间。

保存结果不明时使用「核对当前照片日期」，先读取原照片；页面不会自动重复提交。多人修改产生冲突时保留草稿，核对当前值后再决定。切换成员会清除旧身份的私人内容。

只有照片本人可修改已明确保存的设备静态照片日期。Google 照片、视频、未保存预览、其他成员和电视不支持此编辑；共享和电视投影不包含本人确认日期。
