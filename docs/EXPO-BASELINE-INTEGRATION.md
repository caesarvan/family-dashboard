# Expo 私人资产报告接线

候选未发布。从「财务 → 我的资产与来源报告」打开只读 `FinanceBaselinePanel`，通过 `onBack` 返回原财务视角和月份；「更新资产来源（高级）」继续保留原来源更新入口，本批没有把读取冒充导入或邮箱刷新。

仅成员可挂载财务工作区，身份键改变重建整个工作区。进入报告时，已有账本／预算／共同资金的写入、未知结果或编辑草稿会阻止切换；进入后清除原页显示数据、推进 epoch 并失效读结果。后台财务刷新暂停安装结果。报告自身负责本人会话、隐藏和离线保护；返回后重新读取财务数据，保留原查询而不沿用旧记录快照。失焦／真正身份重置关闭报告；同身份离线可留在报告入口，由各自模块重新核对。

公共改动只在 `frontend/src/screens/FinanceScreen.tsx`。面板和客户端模型由独立作者提供；实际组合类型、浏览器和权限验证完成前，不将本接线视为可上线成果。使用及数据边界见 [我的资产与来源](EXPO-BASELINE.md)，服务端边界见 [私有报告读取](EXPO-BASELINE-READ-API.md)。
