# Expo 本人账户分析

本批为待组合验收的候选，尚未发布。入口：**财务 → 我的资产账户 → 查看我的账户分析**。只分析当前家庭中本人的手动账户，伴侣、电视及共同导出不获得分析明细。

## 查看与选择

默认读取近 90 天、CNY 报告币种和全部本人账户（包含归档）。先显示期末已知资产、负债、净额与覆盖缺口，再显示区间变化、趋势、资产配置和流动性。读报告只使用缓存，不访问外网。

- 「本月」「近三个月」「今年」直接读取相应日期范围。「近三个月」采用最近 90 天；当月或当年第一天时，起点向前一天以保留两个不同日终日期。
- 「自定义范围」展开起止日期、三位报告币种及日／月取样。日期从 1999-01-04 起，包含首尾最多 366 天，起点必须早于终点。点「读取所选范围」应用。
- 「选择本人账户」可搜索、分页勾选。整个趋势始终使用同一组已选账户；归档不代表历史余额归零。不能选择空集合。
- 趋势图只连接当日覆盖完整的相邻取样点。缺估值、金额未知、沿用旧估值或缺汇率时断开；不会把缺失补成零。「查看取样明细与覆盖」展开每个取样日的已知净额与缺口。
- 配置与流动性只统计可折算资产，比例以该已知资产部分为分母，负债单独显示。未分类及未知流动性保留；零金额且无账户的桶不铺在默认界面。

已知部分不代表完整家庭财产。来源报告、持仓、共同荷包、付款账本不参与本分析加总。账户名称、归档状态与分类来自当前设置，不能据趋势推断历史分类。

## 核对单个账户

点「核对 账户名」查看起止估值、原币金额、原估值日期、折算金额及参考汇率日期。沿用估值会标明，最新记录明确未知时不会改用更早的已知金额。补充或修正估值需返回「我的资产账户」按精确日期记录。

「编辑分类与流动性」只更新本人的分析资料，保存采用独立 profile revision。「登记资金进出」填写原币金额、方向、日期及私人备注，再点「保存」。现有事件可以修改；删除需先核对事件并明确确认。已归档账户须先恢复才能编辑分类，或新增、修改、删除事件；历史读取与区间核对仍可用。

资金日期范围为 **(起点日, 终点日]**：起点是日终估值，不再计入起点日资金。资产方向是转入／转出，负债方向是借入／偿付；不自动推断利息、分红、费用或证券交易的现金流性质。账户间转移须本人分别核对两端，不能从单边事件宣称家庭外部收入，也不会再写入付款账本。

「核对区间完整性」显示精确首尾日、两端估值、已登记笔数与净额。只有两端都有当天已知估值，且本人明确勾选已完整核对，才能保存。没有登记事件也须本人确认，空列表不代表没有资金进出。确认仅适用于该账户和精确区间；账户或估值变动、资金事件新增／修改／删除后可能失效，需重新核对。

原币差值始终称为余额变化。确认有效后才显示「扣除资金进出后的估值变动」；这是余额差扣除已核对外部资金后的残差，不能直接叫交易收益、年化收益或投资回报。折算归因分别显示资金进出、按期末参考汇率折算的估值残差、汇率影响和舍入差额；所需汇率缺失时显示「未能计算」。

## 官方参考汇率

「更新官方参考汇率」独立显示所选日期与公共来源说明，点「确认更新汇率」才从服务器固定的 ECB 官方 HTTPS 来源更新。服务器向起点之前多读取七天；不会将账户、金额或身份发送给该来源。失败保留原有缓存，更新不自动重复。

同币种采用恒等换算。不同币种采用同一日期的 EUR 交叉汇率，最多沿用七天，未知币种或缺报价不伪造折算。它是估值参考，不是实际成交汇率。

账户详情「查看汇率来源与日期」按需展开官方来源 URL、报价日期、下载／检查时间、报价 SHA 版本及原件 SHA256；默认总览不展示这些技术字段。

## 保存、离线与恢复

读取与写入均复用本人资产账户的前后 `/me` 身份核对、完整会话身份、CSRF 和请求代次保护。切换成员／家庭或身份失效清除可见私密内容；页面进入后台、离线或从页面缓存恢复时先隐藏，再重新核对当前身份与数据。同一身份未保存草稿仅在内存保留，不写浏览器存储。

版本冲突保留草稿并阻止继续保存。重新读取后可明确「采用当前版本，保留填写内容」，核对当前资料后再保存；若原事件不在当前页，须取消草稿并重新选择事件。

响应丢失或结果不明时显示原操作编号，保留原方法、路径、payload 和 requestId。可「查询原操作结果」，或在原表单仍在内存时「按原请求重试」。找到成功回执后重新读取当前分析，不以历史回执替换当前状态。回执未找到不证明未执行；必须先读回当前资料、明确承认原请求仍可能完成，才可结束本次核对。离开页面不取消已发出的请求，刷新整个应用前应复制编号；「查询以前的操作」可按需输入旧编号。
