脚本及修订经非作者审查后已在固定组合实际执行：R1 为 9/10，R2 为 10/10，并各产出 12 张截图。R2 可见视口审查通过；当前仍未部署。
固定源码、构建、原始失败与完整散列集中见 [组合验收](EXPO-TRIP-RECAP-ACCEPTANCE.md)。后续执行仍须由集成人冻结源码、Expo 导出与构建证据。

## 执行

在本脚本所属工作树运行，使用已有 Python 虚拟环境中的 Playwright、Flask、Pillow，以及已安装的 Edge：

```powershell
python -B -X utf8 tests/browser_expo_trip_recap_check.py `
  --source-root '<已审组合的物理目录>' `
  --expected-head '<完整40位提交>' `
  --bundle '<本提交构建的dist目录>' `
  --expected-build-evidence '<build-evidence.json的SHA256>'
```

不安装依赖、不构建、不访问生产。脚本拒绝源码／构建身份不符、Git dirty、导出或构建输入散列不符；
执行脚本须与组合中的同名文件一致。运行前后复核所有 tracked 文件和导出字节、HEAD 与 clean 状态。

## 十组范围

1. 实际旅行列表进入详情再进入回顾；当前事件独立编辑、合法 8000 字备注、已删事件不复活、八项分页、返回同旅行 fresh 详情。
2. v2 当地时区、住宿未知时刻、人工取消；真实空地点／照片，删除旅行级联删除 workflow，详情及地点接口返回 404 后清除旧回顾。
3. 25 地点与 25 图片使用真实 24 条接口分页；第二页图片经真实鉴权 JPEG 下载，关闭详情不改权限。
4. 伴侣共享／私有、坐标隐藏／大致／精确；真实签名第二家庭隔离，以及真实配对电视拒绝成员地点和照片读取。
5. 实际撤共享后清图、显式同页恢复；在真实图片请求前删除记录得到 410，再显式恢复图库。旧 Blob URL 必须不可再读取。
6. 真实成员 cookie 改变后，延迟送达的本人图片列表不得重新显示；等待实际 actor 重挂终态。
7. 真实签名家庭 cookie 改变后的同类隔离。
8. 浏览器实际离线；模拟 visibility 与 window blur/focus；隐藏期间迟到响应不能复活，online 不绕过 blur；真实等待 15 秒重新核对、清旧图。
9. 丢弃真实 GET 回应后明确重试；读取在途返回旅行后，迟到结果不能重新打开面板。
10. 320／390／1280／1920 四宽的浅色行程、长地点、深色紧凑照片，实际十二张截图；抽查回顾主操作区控件 44px、无可见横溢、键盘关闭与焦点。

每组独立临时目录、SQLite、Flask HTTPS server、浏览器 context 与清理栈；失败留图、ARIA 与 traceback，继续其他独立组，整轮仍失败。
复用真实 `browser_expo_finance_check.Run` 的隔离启动与登录；媒体使用真实创建／确认接口和真实引擎状态机，
仅云端任务完成值与 Pillow 图片为虚构 fixture。业务成功 JSON 和 JPEG 不替换，故障只延迟／丢弃真实回应。
临时数据库连接全部关闭，网络限制为本次 loopback 来源；不读真实照片、云账户或财务。

报告写入自身 ignored `test-results/expo-trip-recap-<UTC>/result.json`，绑定源码／fixture／构建／导出／截图散列和逐组清理结果。
R1／R2 各十二张图均由 Root 逐张查看，独立记录在各报告目录的 `visual-review.json`。R1 手机深色截图未覆盖图片本体；R2 改为滚动至图片，四宽均包含图片区域，手机说明与下方按钮仍可能在视口外。截图不涵盖全部内部滚动内容。
visibility、blur/focus 是显式事件模拟；不宣称实体手机失焦、浏览器冻结时即时清屏、原生 App 或实体电视验收。
当前各接口分别读取，不构成跨模块原子快照；回顾不证明真实出行、路线、照片拍摄地点或自动到访。
