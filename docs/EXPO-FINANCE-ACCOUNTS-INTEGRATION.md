# 资产账户页面接入

本分支在已审查的账户 API、应用注册和 UI 组合之上，新增财务页「我的资产账户」入口。
入口使用独立面板，保留原账本月份；返回后重新读取财务内容。

`FinanceScreen` 将账户面板的草稿、正在保存与未知结果传给 `HouseholdApp`。
导航保护按完整身份、当前 finance 路由及 finance-accounts 来源校验；旧面板回调不能清除新面板的锁。
打开面板会隐藏旧财务数据并失效旧请求。面板明确返回后先解除自己的 pending，再回财务重新读取。
身份变化清空旧面板状态；户外或电视身份不能使用个人账户页。

本次仅接入三份前端文件，不修改 API、迁移或其他页面的业务处理。
API 与 UI 专项检查属于各自固定作者版本；组合 TypeScript、构建及真实临时浏览器已实际通过。
55→58 迁移与发布已独立执行，见 [发布验收](EXPO-FINANCE-ACCOUNTS-ACCEPTANCE.md#finance-accounts-release)。
