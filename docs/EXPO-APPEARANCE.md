# Expo 成员外观

**已于 2026-09-17 16:17:28（北京时间）发布，16:17:57 正常 TLS 读回通过。** 使用下方步骤调整本人外观。正式运行源码与此前 R1 浏览器受验源码分别记录，完整身份、Linux 结果及保全原件见 [本轮验收](EXPO-APPEARANCE-ACCEPTANCE.md#expo-appearance-release)；发布后文档不会改写运行包。

## 使用方法

1. 使用成员账户，从「更多 → 外观设置」打开「我的外观」。
2. 选择「浅色」或「深色」，再选择「标准」或「紧凑」内容密度。选择先保留为草稿。
3. 点击「保存外观设置」。看到「外观设置已保存」后，新外观立即应用；面板继续保留，选择「返回更多」退出。
4. 不想保存时，选择「放弃修改并返回 → 确认放弃修改」。正常保存只需一次明确点击。

外观属于本人及当前家庭，同一成员的手机、电脑读取同一份设置；伴侣保持自己的选择。电视从「电视与播放」单独设置，成员外观不会更改电视主题、密度、日程范围或照片许可。

## 冲突和中断时

| 情况 | 下一步 |
| --- | --- |
| 另一设备先保存，版本冲突 | 点击「查看最新外观设置」，核对后选择「采用当前设置」或「保留我的修改」。保留后有差异才再次明确保存。 |
| 保存前身份检查失败 | 草稿保持，页面提示错误；尚未尝试 PUT 时不会标记为未知写。 |
| 已尝试保存，但回复或后置身份核对失败 | 点击「核对外观保存结果」只读取当前状态，再明确采用或保留修改；不自动重发保存。 |
| 同身份下离线、进入后台或失去焦点 | 隐藏内容并取消旧请求，草稿和未决意图只留在内存。返回后核对身份和当前版本；同版本恢复草稿，版本变化则明确选择。 |
| 成员、家庭、认证版本或 CSRF 变化 | 清除旧身份草稿；迟到响应不能重新显示旧内容。 |

GET 读到相同值不代表取得了上次请求的回执。编辑、保存及未知结果期间有根导航保护；草稿不写 URL 或本地存储，强制关闭浏览器后不提供跨会话恢复。

日程的「今日／本周／前后 3 天」继续在原位置操作，同样使用版本保护并只保存 `homeView`。若结果未知，使用全局「核对显示设置」读取当前范围，再决定是否重新选择；不会把网络失败显示成保存成功。

## 覆盖与兼容

浅色沿用 Expo 官网的白、灰、黑和圆角层级；深色使用深灰背景、浅色正文及反色主按钮。密度主要调整导航、页头、共享卡片和首页的留白，不缩小字号或改变卡片顺序；日程及清单内部间距尚未全面接入。账户连接、家庭资金、持仓的固定底色已替换为主题语义色，业务请求不变。

新增面板选择行实测 48px、动作按钮至少 44px；首页待办勾选实测 44px，空格键只发出一次真实 PATCH。既有首页日程范围按钮实测 34px，本轮没有将其计为满足 44px，不声称全页面达标。源码、模型检查和局部颜色取样也不等于所有页面、弹窗、图片区域或实体设备都通过视觉／可访问性验收，具体实现范围见 [样式说明](EXPO-APPEARANCE-STYLE.md)。

`/classic` 的「让这里更像你们的家」仍管理原 `theme`、密度和默认日程范围；`theme: forest/light/ocean` 与新版 `colorMode: light/dark` 分开，旧界面不会覆盖未编辑的 `colorMode`。经典保存使用同一 CAS 协议；失败后「检查已保存设置 → 使用已保存设置／保留我的草稿」，不自动 PUT。后台／离线时隐藏，恢复经过完整身份核对，同账号草稿保留，旧请求不能解除新操作的忙碌状态。

## 开发接缝

| 位置 | 职责 |
| --- | --- |
| `AppearancePanel.tsx`、`preferences.ts` | 草稿、字段差异、前后身份核验、冲突／未知结果选择、生命周期与请求取消。 |
| `household.tsx` | 按完整身份和单调 revision 安装已确认偏好；阻止旧轮询覆盖刚保存结果；日程范围也走 CAS。 |
| `HouseholdApp.tsx`、`OtherScreens.tsx`、`types.ts` | 更多中的内存面板与 `appearance` 来源导航锁；不会清除设备、布局或改期的锁。 |
| `_layout.tsx`、`theme.ts`、共享组件及首页 | 只在已确认成员下消费 `colorMode`／`density`；TV 首帧走独立分支。 |
| `household_spaces.py`、`static/product-shell.js` | 服务端真实会话与事务检查，以及 classic 客户端 CAS／生命周期兼容。 |

复用 `GET /api/preferences` 和 `PUT /api/preferences`；读取平铺 `{theme,density,homeView,colorMode,revision}`，保存只提交 `{revision,changes}`。未知字段不接受新建，未提交的字段保持；旧无版本写返回 400，版本冲突 409，同值不增加版本。没有操作回执接口，不新增表、依赖或路由。默认 `forest / comfortable / today / light / 0`，完整契约和后端证据见 [成员偏好 API](MEMBER-PREFERENCES-API.md)。
