# Expo 来源导入浏览器验收

本文件是待执行的专项计划，不代表浏览器通过或已经发布。脚本 `tests/browser_expo_finance_source_check.py` 只在集成人提供已审组合 source、完整 HEAD、真实导出目录和 build-evidence SHA256 后运行；当前仅做静态编译和源码审查。

复用 `browser_expo_finance_check.Run` 的真实临时 Flask／SQLite、HTTPS loopback、HttpOnly 成员与电视配对 cookie、Edge。来源 JSON 由 `test_finance_source_bridge.synthetic_candidate` 和 `test_spending_observations.observation` 生成，全部为虚构数据。两种成功响应都来自实际 API；故障仅丢弃真实请求、丢失或延迟真实响应，不能替换成功 DTO。

计划 12 个独立流程：

1. 文件选择、预览零业务写、键盘明确确认、完整资产持久化及真实后端重启。
2. 粘贴消费观察，仅其独立版本线改变；原资产整行、共同资金、账本、持仓保持。
3. 畸形 JSON、体积超限、更新范围不符的本地拒绝，以及真实服务端金额拒绝。
4. 预览后另一设备实际更新来源，409 不覆盖；保留草稿后明确重新预览、确认。
5. 实际提交后丢失响应：顶部导航保持锁定，精确 operationId GET 恢复，只有一次 POST。
6. 消费观察实际提交后丢失响应，明确原 candidate／token 重试返回同一回执，不二次更新。
7. 请求未送达：found=false 仍未知；fresh GET 后显式「结束本次核对」及二次确认，才能选择来源重新预览；不自动 POST。
8. 无回执过期 token 精确410；真实新登录后仍可读取和回放已提交的历史，不能借回执恢复旧数据。
9. 两成员、独立第二家庭、匿名和真实配对 TV 的来源／回执／确认边界，不显示他人私密信息。
10. 真实预览返回前切换成员 cookie，旧面板卸载，迟到 DTO／草稿不进入新身份。
11. 草稿与未知结果的全局导航锁、明确返回保留月份；隐藏／离线销毁私密输入，未决编号仅保留为只读恢复入口。
12. 320／390／1280／1920 四宽的浅色完整来源、深色紧凑消费预览、真实回执，共计划12张稳定可见区域截图；核长文本、横向溢出与主要按钮至少44px。

每个流程使用新的临时目录、应用、监听器和浏览器上下文，关闭资源后才进入下一例。失败留下独立 traceback／截图／ARIA 原件，继续其余流程；任一流程或清理失败都令整轮失败，分轮成功数不相加。精确 token 年龄通过真实 signer 的时间夹具推进，不声称等待了真实20分钟。后台通过可见性事件模拟，断网使用浏览器 offline。

报告绑定 head／tree、执行脚本及直接夹具 SHA、全部 tracked 源和导出前后散列、build-evidence、逐例清理、页面错误与外部请求。禁止非 loopback 请求，不读取真实财务文件或生产数据，不调用真实金融／云服务或部署。截图只覆盖各目标滚动后的当前区域，需另作实际视查；不据此声称整页、原生应用或实体设备已验收。

源码冻结与实际运行参数由集成人分别记录。静态编译不会导入夹具、启动服务、运行 pytest、构建 Expo 或执行浏览器。
