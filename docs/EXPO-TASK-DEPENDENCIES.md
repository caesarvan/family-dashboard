# 本地待办的前置事项

状态：独立前端候选，需与后端依赖合同一起审查、构建和验证。尚未部署，不代表真实账号或浏览器流程已验收。

在「共同待办 → 添加／编辑 → 前置事项」搜索并勾选已有本地待办，最多 20 项。已选择的事项始终列出；已失效引用可以明确取消。候选排除自己、同步清单和会形成互相等待的事项。每次最多显示 20 个候选，更多内容通过关键词筛选。

新建任务可选择「看板本地待办」。同步清单暂不支持前置事项，切换到同步目的地不会默默清除选择，需明确清空或返回本地目的地。云镜像的依赖能力仍未实现。

首页和共同待办显示尚未完成的前置事项。受阻的未完成任务不能勾选完成，仍可编辑或解除依赖；首页在到期范围内优先展示可以执行的任务。已完成任务不会因前置事项重新打开而自动撤销完成状态。

编辑器在明确保存时发送 `dependsOn` 原 ID 数组、原 revision 和其他已有字段；空数组表示明确解除。保存前的本地提示只是辅助，服务端仍须在同一写事务中核对实时状态、循环、身份和权限。发生 409 时显示服务端原因并保留输入；未知保存结果仍禁用保存和选择，先关闭并刷新核对，不自动重发。

旧数据没有 `dependsOn` 时按无前置关系显示；格式损坏时禁用完成，编辑器不静默改为空数组，需明确清空后重新选择。`blockedBy` 与 `dependencyStatus` 只用于展示，不作为写入字段。

实现位于 `taskDependencies.ts`、`TaskDependencyFields.tsx`、现有 ItemEditor／ListScreen／HomeScreen；复用 Paper、SelectionRow 的键盘和选中状态，保持当前主题及排版。
